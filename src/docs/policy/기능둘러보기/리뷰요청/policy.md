# 리뷰 요청

## 개요

알파리뷰는 기본적으로 실제 구매 고객만 리뷰 작성 가능하지만, **서포터즈나 협찬처럼 주문 건이 없는 상황에서 리뷰 요청 기능을 사용하면 비구매 고객도 리뷰 작성 가능**합니다.

### 주요 특징
- **임의 주문 생성**: 알파리뷰 시스템 내에서만 주문 건 생성 (호스팅사 비연동)
- **알림톡 자동 발송**: 파일 업로드 당일 또는 익일 오후 7시경 발송
- **비회원 처리**: 생성된 주문은 모두 비회원 상태로 처리
- **수동 입력**: 상품 정보, 고객 정보 등을 엑셀에 직접 입력

### 제약사항
- 호스팅사(카페24/아임웹) 주문 데이터로 연동되지 않음
- 알림톡 발송 후에는 주문 건 삭제 불가
- 알림톡 발송 전 데이터 변경 가능
- 파일 형식 변경 시 정상 등록 안 될 수 있음

## 접속 경로

**`리뷰 관리 > 리뷰 요청`**

### 화면 구성

| 메뉴 | 설명 |
|------|------|
| [엑셀 양식을 다운로드] | 다수 주문 건을 한 번에 생성할 때 사용 |
| [주문 직접 입력하기] | 소수 주문 건을 개별 생성할 때 사용 |
| 이미 리뷰 요청한 내역이 있나요? | 기존 생성 주문 건 확인 및 삭제 |

## 엑셀 작성 방법

### 필수 입력 필드

| 필드명 | 설명 | 유의사항 |
|--------|------|---------|
| 주문 번호 | 임의로 지정 | 숫자만 입력 가능, 1명당 1개 번호 부여 필수 |
| 상품 코드 | 호스팅사 상품 코드 | 반드시 일치해야 정상 등록 |
| 상품명 | 상품 이름 | 쇼핑몰에 표시됨 |
| 가격 | 상품 가격 | 쇼핑몰에 표시됨 |
| 옵션 | 상품 옵션 정보 | 쇼핑몰에 표시됨 |
| 주문자 이름 | 고객 이름 | - |
| 주문자 전화번호 | 고객 연락처 | 알림톡 발송에 사용 |

### 작성 단계
1. **파일 다운로드**: [엑셀 양식을 다운로드] 클릭
2. **정보 입력**: 다운로드한 파일에 주문 정보 입력
3. **파일 업로드**: [업로드] 텍스트 클릭하여 파일 선택
4. **정보 확인**: 업로드 후 데이터 검토
5. **리뷰 요청 완료**: [리뷰 요청] 버튼 클릭

### 중요 사항
- **파일 형식**: 엑셀 파일로 저장 (한셀 불가)
- **형식 유지**: 다운로드 받은 원본 형식 그대로 저장
- **상품 코드 일치**: 호스팅사 코드와 반드시 일치
- **알림톡 예약 후**: 데이터 변경 불가능

### 예상 처리 시간
- **알림톡 발송**: 파일 업로드 당일 또는 익일 오후 7시경
- **리뷰 작성 가능**: 파일 업로드 후 3~4시간 후부터

## 직접 입력 방법 (개별 주문 생성)

### 진행 단계
1. **버튼 클릭**: [주문 직접 입력하기] 클릭
2. **정보 입력**: 주문 정보 및 고객 정보 입력
3. **완료**: [리뷰 요청] 버튼 클릭

### 주문 번호 입력 규칙
- **숫자만 입력**: 기호(-) 등 불가능
- **1명 다중 상품**: 동일 주문 번호로 여러 상품 등록 가능
- **1명당 1 번호**: 고객당 하나의 주문 번호 부여

## 주문 확인 및 삭제

### 확인 방법
1. 내역 페이지 이동: "이미 리뷰 요청한 내역이 있나요?" 클릭
2. 파일명 클릭: 업로드된 파일 선택
3. 상세 정보 확인

### 삭제 방법
1. 내역 페이지 이동
2. 파일명 클릭
3. [발송 취소] 영역의 휴지통 모양 아이콘 클릭

### 삭제 제약사항
- **알림톡 발송 후**: 주문 건 삭제 불가
- **복구 불가**: 삭제 시 복구 불가, 새 파일로 재등록 필요
- **발송 전**: 발송 취소 전에는 데이터 수정 가능

## 주요 정책 및 유의사항

### 알림톡 관련
- 이 기능을 통해 주문 건을 등록해도 호스팅사 상에는 주문 건이 생성되지 않음
- 알림톡 발송 여부와 관계없이 파일 업로드 후 리뷰 작성 가능
- 리뷰 요청의 알림톡은 주문 번호 및 배송 조회 버튼 제외

### 주문 처리 방식
- 호스팅사 고객 정보와 비연동 (비회원 처리)
- 실제 주문 데이터 미포함
- 알파리뷰 시스템 내에서만 독립적으로 관리

### 데이터 관리
- 파일 형식 변경 시 정상 등록 불가능
- 상품 코드 불일치 시 등록 실패
- 알림톡 예약 후 데이터 변경 불가
