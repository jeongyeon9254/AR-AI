# 알파리뷰 기본 기능 - "알림톡" 가이드

## 개요

알림톡은 알파리뷰의 기본 기능으로, 카카오톡을 통해 고객에게 리뷰 작성을 유도하는 정보성 메시지입니다. 별도 설정 없이 서비스 개시 직후부터 자동으로 작동됩니다.

## 알림톡이란?

- **정의**: 카카오톡을 통해 발송되는 정보성 메시지로, 상품 구매 고객에게 리뷰 작성을 유도합니다
- **발송 대상**: 호스팅사(카페24/아임웹) 연동 후 배송 완료된 주문 건부터 적용
- **발송 시간**: 리뷰 작성률이 높은 19시경에 1일 1회 일괄 발송 (변경 불가)
- **대체 수단**: 카카오톡 미사용 고객은 SMS로 자동 발송

### 발송 제외 대상
"리뷰 작성이 불가능하거나 혜택 지급이 제한된 주문 건은 발송되지 않습니다"

### 발송 내역 확인
경로: [내역 > 메시지 발송 내역]에서 확인 가능

## 알림톡 발송 횟수

### 1. 첫 번째 요청
- 주문 건이 알파리뷰에 최초 연동되었을 때 **1회** 발송
- "리뷰 요청" 기능 사용 시에도 동일하게 1회 발송

### 2. 회원가입 유도 알림톡
- **조건**: 비회원 리뷰 작성 허용 설정 + 지급 가능한 적립금 발생 시
- **발송 횟수**: 비회원 고객의 경우 리뷰 작성 유도/회원가입 유도 알림톡 **총 2회**
- **동의 필수**: 고객 동의 시에만 발송

### 3. 리마인더
- 첫 번째 요청 후 n일 경과 시에도 미작성 고객에게 발송
- 리마인더 사용 시 일반 고객에게는 **총 2회의 리뷰 작성 유도 알림톡** 발송

### 4. 발송 취소/재발송
관리자 페이지 [기본 설정 > 알림톡 및 메시지 설정 > 알림톡 설정]에서 가능하며, **각각 1회만** 가능합니다.

## 알림톡의 장점

### 경제성
- **요금**: 건당 12원 (SMS 14원 대비 저렴)
- **무료 제공**: 매월 5,000원어치 무료 제공

### 신뢰도
"카카오톡은 스팸 규제가 까다로워 사용자가 SMS보다 카카오톡 메시지에 더 높은 신뢰도를 가집니다"

### 다양한 기능
- **빠른 리뷰**: "만족/보통/별로" 버튼 클릭으로 즉시 리뷰 작성 가능
- **동적 메시지**: 발송 시점에 따라 "[발송 완료]/[배송 완료]" 문구 자동 변경
- **리뷰 요청 기능**: 주문번호 및 배송조회 문구 제외하여 발송 가능

## 알림톡의 단점 및 제약사항

### 마케팅 규제
카카오톡은 정보성 메시지만 허가하므로, 마케팅성 내용이 포함되면 발송이 불가능합니다. 알파리뷰는 규제 범위 내에서 최대한 효과적인 템플릿을 지속적으로 검수받고 있습니다.

### 주문 건 연동 필수
주문 건 확인이 필요하므로 오프라인 구매자에게는 자동 발송이 불가능합니다. 이를 보완하기 위해 **리뷰 요청 기능**을 제공합니다.

### 기능 비활성화
이 기능을 사용하지 않을 경우 "리뷰 작성률이 큰 폭으로 올라가지 않을 수 있어 권장하지 않습니다"

## 주요 설정 정보

### 알림톡 설정 위치
- **경로**: 관리자 페이지 > 기본 설정 > 알림톡 및 메시지 설정 > 알림톡 설정

### 설정 내용
- 발송 시점 설정 (발송 완료/배송 완료)
- 리마인더 발송 일수 설정
- 발송 취소/재발송 관리

## 운영 정책 및 주의사항

### 기본 정책
1. 서비스 개시 이후 배송 완료된 주문부터 발송
2. 1일 1회 일괄 발송 (발송 시간 변경 불가)
3. 리뷰 작성 불가능한 주문은 자동으로 제외
4. 비회원 고객도 리뷰 작성 가능 (별도 설정 필요)

### 권장사항
알림톡 기능의 사용을 권장하며, 미사용 시 리뷰 작성률이 크게 낮아질 수 있습니다.

## 자주 묻는 질문 (FAQ 요약)

- **발송 시간 변경 가능?**: 불가능 (19시경 고정)
- **발송 문구 수정 가능?**: 카카오톡 규제로 인해 템플릿 선택 범위 내에서만 가능
- **비회원 리뷰 작성?**: 가능하며, 지급 가능한 적립금 발생 시 회원가입 유도 알림톡 발송
