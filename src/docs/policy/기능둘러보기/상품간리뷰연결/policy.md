# 상품간 리뷰 연결

## 개요

상품간 리뷰 연결은 상품을 연결시켜 리뷰를 공유하는 기능입니다. 단일 상품들을 묶어 세트로 판매하거나 옵션별로 상품을 나눠 판매할 때, 하나의 상품에 작성된 리뷰들을 다른 상품에서도 보여지도록 할 수 있습니다.

## 핵심 개념

### 두 가지 연결 방식

#### 1. 그룹 연결 (양방향 연결)
- A, B, C 상품을 서로 연결하는 방식
- 연결된 모든 상품에서 동일한 리뷰가 보여짐
- **사용 시기**: 같은 상품의 다른 옵션들을 각각 판매할 때

#### 2. 단방향 연결
- A 상품의 리뷰를 B, C 상품에 노출
- A+B 상품의 리뷰를 C 상품에만 노출
- **사용 시기**: 다른 상품들을 세트로 판매할 때

## 필독사항 (사용 전 반드시 확인)

### 중요 정책

1. **연결 세트의 역할**: 연결 세트에 포함되지 않는 상품끼리는 리뷰가 연결되지 않음
   - 예: A→B 단방향, B↔C 양방향 연결 시 → A와 C는 직접 연결 안 됨 (B를 통해서만 공유)

2. **상품 삭제 후에도 유지**: 호스팅사에서 상품을 삭제해도 알파리뷰 DB에 리뷰 데이터가 남아있으면 연결 세트와 리뷰 공유 유지

3. **향후 리뷰도 공유**: 연결 후 작성되는 모든 리뷰가 공유됨

4. **리뷰 설정도 공유**: 리뷰 상단 고정 등의 리뷰 설정도 모두 공유됨

5. **삭제 불가**: 삭제된 연결 세트는 복구 불가능

6. **시간 소요**:
   - 호스팅사 신규 상품 등록 → 대시보드 연동: 최소 3~4시간
   - 상품간 리뷰 연결 → 리뷰 공유: 최대 10~15분
   - 상품간 리뷰 연결 → 리뷰 개수/별점 연동: 최소 1시간, 최대 4~6시간

## 사용 방법

### 접속 경로
**`리뷰관리 > 상품 간 리뷰 연결 > + 연결 추가`**

### 단계별 설정

#### 1단계: 페이지 접속
기존 연결 세트 수정 시에도 동일한 경로 접속 후 해당 연결 세트 옆의 '수정' 버튼 클릭.

#### 2단계: 연결 방식 선택
- 그룹 연결 (양방향) 또는 단방향 연결 중 선택
- 연결 방식은 언제든 변경 가능

#### 3단계: 연결할 상품 선택
- 목록에서 연결할 상품 추가
- **단방향 연결 시**: 상단 화살표 방향으로 리뷰 연결 방향 지정
  - 1개 상품에 여러 상품 리뷰를 연결하려면 화살표를 오른쪽으로 변경
- 이미 선택된 상품의 "추가됨" 버튼 클릭으로 세트에서 제외 가능

⚠️ 호스팅사에서 새로 등록한 상품은 알파리뷰 연동에 최소 3~4시간 소요.

#### 4단계: 제목 입력 및 저장
- 리뷰 연결명 입력 (필수)
  - 제목 미입력 시 저장 불가
  - 중복된 제목 사용 불가
- 관리자가 구분할 수 있는 이름으로 변경 권장
- "저장하기" 버튼 클릭

### 리뷰 연결 유의사항

각 상품에 작성되어있는 리뷰만 연결됨.

예: A상품에 20개 리뷰, A-B 그룹연결된 상태에서 자사몰에는 50개가 보여도, A-C 그룹연결 시 A상품의 20개 리뷰만 연결 (B상품의 30개는 B-C 미연결이므로 제외).

## 연결 세트 검색

상품명, 상품코드, 연결이름으로 어떤 상품이 어떤 연결 세트에 포함되어있는지 검색 가능.

- 상품명 검색 시: 해당 상품이 추가되어있는 연결 세트들만 모아서 확인 가능
- **활용**: A 상품에서 B 상품의 리뷰가 나올 때 기존 연결 세트 확인용
