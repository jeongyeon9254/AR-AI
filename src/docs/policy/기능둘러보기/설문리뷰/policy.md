# 설문 리뷰

## 개요

설문 리뷰는 고객에게 원하는 답변 또는 프로필 등의 데이터를 리뷰로 작성하도록 제공되는 기능입니다. 상품을 구매한 고객의 키, 몸무게, 피부 타입 등의 정보를 수집하여 구매 검토 중인 고객에게 더 풍부한 정보를 제공합니다.

### 주요 역할
- 구매 경험자가 구매 검토자에게 유용한 정보 전달
- 고객 프로필, 상품, 서비스 관련 데이터 수집
- 리뷰의 신뢰도와 유용성 향상

## 설문 리뷰 설정 방법

### 기본 활성화

**접속 경로:**
1. `기본 설정 > 리뷰 모아보기 > 설문 리뷰 활성화`
2. `기본 설정 > 설문 리뷰 > 설문 리뷰 사용 활성화`

**중요 사항:**
- 설문 리뷰 기능 사용 시 반드시 활성화되어야 함
- 비활성화 상태에서는 고객이 설문 리뷰 작성 불가
- 설정 변경 후 들어오는 주문 건부터 적용

## 설문 항목 설정

### 설문 항목 추가하기

**접속 경로:** `기본 설정 > 설문 리뷰`

**절차:**
1. 고객에게 답변받고 싶은 설문 항목 추가
2. 고객 프로필/상품/서비스 관련 템플릿 제공
3. 원하는 템플릿 선택 후 완료 버튼 클릭

**제약사항:** 기본 제공 템플릿은 옵션 수정 불가능.

### 자동 저장 기능

고객 정보에 대한 기본 템플릿은 답변 정보가 자동으로 저장되어, 다음 리뷰 작성 시 자동으로 불려옴 (키, 몸무게 등). 자동 저장을 원하지 않으면 체크 해제 후 새 설문 항목 생성.

### 설문 직접 만들기

기본 템플릿에서 원하는 항목이 없는 경우, "+ 설문 직접 만들기"로 커스텀 설문 생성.

### 설문 항목 관리하기

- **관리자만 보기**: 체크박스 선택 시 설문 답변이 쇼핑몰에 노출되지 않음 (서비스 답변, 마케팅 동의 수집 용)
- **항목 순서 변경**: 드래그로 순서 변경
- **항목 삭제**: 휴지통 아이콘 클릭 (템플릿은 유지됨)

### 설정 제약사항
- **최대 설문 항목 수: 7개**

## 설문 리뷰 포인트 설정

설문 리뷰는 필수 작성이 아닌 선택 사항이며, 포인트 지급으로 작성률 향상.

**접속 경로:** `기본 설정 > 포인트 지급 설정`

**포인트 지급 조건**: 설문 리뷰 항목이 여러개인 경우 **모든 항목을 작성했을 때**만 적립금 지급.
(예: 5개 중 4개만 작성 시 미지급, 5개 모두 작성 시 지급)

## 설문 리뷰 확인 방법

### 테스트 방법
현재 알파리뷰는 테스트 알림톡 발송 기능을 제공하지 않음.

**대체 방법:**
1. 리뷰 요청 기능으로 알림톡 수신
2. 실제 리뷰 작성으로 설정된 설문 항목 확인

### 주문 건 제약사항
설문 리뷰 활성화 **전** 이미 연동되어있던 주문 건은 설문 리뷰 작성 불가. **새로운** 주문 건부터 작성 가능.

## 설문 리뷰 노출 위치

### 관리자 대시보드
- 리뷰 목록에서 작성된 설문 답변 확인

### 고객 노출 영역
- 평점 위젯/게시판 위젯에서 답변 항목 함께 노출
- 프리미엄 브리핑 위젯: 필터 기준으로도 활용 가능

### 위젯 노출 제어

**접속 경로:** `디자인 설정 > 위젯 세트 관리 > 설정`

"설문" 항목 체크 해제 시 위젯 내 설문 답변 미노출. 노출만 제어하며 작성은 계속 가능.

## 설문 분석 및 통계

**접속 경로:** `통계 > 설문 분석`

- **선택형 답변**: 각 항목의 분포율 시각화
- **주관식 답변**: 언급되는 키워드들을 한 번에 확인

## 설문 리뷰 데이터 다운로드

**접속 경로:** `리뷰 목록 > 오른쪽 상단 다운로드 버튼`

다운로드 시 설문 리뷰 데이터 포함 여부 체크.

**다운로드 정책:**
- 처리 시간: 평균 3~4시간
- 유효 기간: 7일
- 데이터 제한: 6개월 이상이 필요하면 6개월 단위로 분할 요청

## 주요 기능 및 제약사항 정리

| 항목 | 내용 |
|------|------|
| 최대 설문 항목 | 7개 |
| 포인트 지급 | 모든 항목 완성 시만 지급 |
| 자동 저장 | 기본 템플릿은 답변 자동 저장 (해제 가능) |
| 활성화 시점 | 활성화 후 새 주문부터 적용 |
| 템플릿 수정 | 기본 템플릿 옵션 수정 불가 |
| 노출 제어 | 위젯 설정으로 노출 여부 선택 가능 |
