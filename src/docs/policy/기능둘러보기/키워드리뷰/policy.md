# 키워드 리뷰

## 개요

### 개념
키워드 리뷰는 고객이 경험한 내용을 간단하게 선택해서 작성할 수 있는 기능입니다. 네이버 스마트플레이스의 키워드 리뷰 기능에서 영감을 받아 자사몰 맞춤형으로 개발되었습니다.

### 특징 및 효과
- **고객 선호도**: 81% 고객은 단순 별점 리뷰보다 키워드 리뷰를 선호
- **리뷰 품질 향상**: 텍스트 리뷰 작성 전 키워드를 선택하면 고객의 작성 부담을 줄임
- **전환율 개선**: 상세페이지에 키워드 요약 위젯으로 Social Proof를 제시하여 구매전환율 상승 기대

### 표시 위치
- 게시판 위젯에 키워드 표시
- 상세페이지 상단에 키워드 요약 위젯 표시

## 내맘대로 키워드 설정하기

### 설정 조건
키워드 리뷰 설정 활성화 후 **연동되는 주문 건부터** 키워드 리뷰 작성 가능. 관리자가 직접 작성할 수 없고, 상품 구매 고객만 리뷰 작성 페이지에서 작성 가능.

### 설정 방법

#### 1단계: 기능 활성화
키워드 리뷰 사용 활성화 시 리뷰 작성페이지에서 키워드 리뷰 작성 활성화.

#### 2단계: 키워드 선택
키워드 선택 버튼 클릭 → 키워드 설정.

#### 3단계: 저장
체크박스 클릭으로 키워드 선택 → 저장.

#### 4단계: 삭제 (선택사항)
키워드 오른쪽 아이콘 클릭으로 추가된 키워드 삭제.

### 제약사항
- 제품/서비스별로 **최소 3개 ~ 최대 15개**까지 키워드 지정 가능
- 새로운 키워드 사용을 원하면 제안 폼 제출 필요

## 작성페이지 표시

### 키워드 요약 위젯 구성 영역
1. **상품 요약 영역**
2. **키워드 통계 영역**
3. **추천 리뷰 영역**

## 키워드 위젯 활용하기

### 설치 위치

#### 자동 설치
키워드 리뷰 위젯 사용 활성화 시 상세페이지 상세정보 영역 최상단에 위젯이 자동 설치 (별도 설치 불필요).

#### 자동설치 미작동 시
자동설치 토글 활성화에도 위젯이 표시되지 않을 수 있음. 이 경우 수동 설치 진행.

### 수동 설치
웹사이트 플랫폼별(카페24, 아임웹 등) 별도 수동 설치 가이드 제공.

### 사용 방법 및 옵션

#### 키워드 개수 설정
키워드 리뷰가 n개 이상 작성 시 위젯이 자동 표시되도록 최소 기준 설정 가능.

#### 위젯 제거
키워드 리뷰 위젯 미사용 시 페이지 하단의 위젯 제거 버튼으로 제거 가능.

#### 색상 설정
키워드 요약 위젯의 포인트 색상은 `디자인 설정 > 공통 디자인`의 기본 색상이 적용.

#### 추천 리뷰 설정
키워드 요약 위젯의 추천 리뷰 영역에 표시할 리뷰에 "키워드 요약" 특수 라벨 지정 필요.

## FAQ

### Q. 자동설치 토글을 활성화했는데 위젯이 표시되지 않아요
키워드 리뷰가 작성되어야 위젯이 표시됨. 또한 플랫폼에 따라 수동 설치 필요할 수 있음.

### Q. 지정된 키워드 외 다른 키워드를 사용하고 싶어요
공식 제안 폼을 통해 키워드 추가 요청 가능.

### Q. 키워드는 몇 개까지 설정 가능한가요?
**최소 3개 ~ 최대 15개**까지.
