# 네이버 블로그 게시물 연동 가이드

## 개요

알파리뷰의 소셜 리뷰 연동 기능으로 네이버 블로그 게시글을 제품 리뷰로 등록할 수 있습니다. 이를 통해 고객의 블로그 포스팅을 쇼핑몰 위젯에 자동 노출시킬 수 있습니다.

## 주요 정책 및 제약사항

### 포토 리뷰 제한
- "알파 리뷰의 정책 상 포토 리뷰는 최대 10장까지만 표시가 가능하기 때문에, 블로그 게시글 내 첫 10장의 이미지까지만 리뷰로 게시됩니다"

### 저작권 및 동의
- 네이버 일반 사용자의 게시글을 등록하는 기능이므로, 게시글을 리뷰로 내보내기 전 작성자의 동의 획득을 권장합니다

### 원본 삭제 시 처리
- 작성자가 원본 게시글을 삭제하더라도 연동된 리뷰는 그대로 유지됩니다
- 연동된 블로그 리뷰는 자동 삭제되지 않습니다

## 접속 경로

**[리뷰관리 > 인스타 & 네이버 블로그 > 네이버 블로그]**

## 게시글 연동 방법

### 1단계: 상품 선택
- 네이버 블로그 게시글을 연동할 상품을 선택합니다
- 상품 중복 선택은 불가능하며, 1개의 상품만 선택 가능합니다
- 1개의 게시물을 1개의 상품씩 연동하며, 중복으로 여러 게시물을 한꺼번에 연동할 수 없습니다

### 2단계: 작성자 정보 입력
- **작성자 이름(필수)**: 게시글을 작성한 고객의 이름 또는 닉네임을 입력합니다. 위젯에 표시될 작성자명입니다
- **호스팅사 아이디(선택)**: 카페24 또는 아임웹 아이디를 입력하면 고객에게 적립금을 지급할 수 있습니다. 확인이 어렵다면 생략 가능합니다

### 3단계: URL 입력 및 연결 확인
- "https://" 부분을 포함한 블로그 게시글의 URL을 입력합니다
- **연결 확인 버튼** 클릭: 알파리뷰 시스템이 유효한 URL인지 확인합니다. 반드시 이 단계를 거쳐야 합니다
- **URL 형식**: https://blog.naver.com 으로 시작하는 링크 사용
- 블로그 게시물 상단에서 게시물별 URL을 복사할 수 있습니다

### 4단계: 리뷰 등록
- 유효한 게시글일 경우 "리뷰로 만들기" 버튼이 활성화됩니다
- 버튼을 클릭하여 리뷰를 등록합니다
- 등록 후 알파리뷰 대시보드의 "리뷰 관리" 메뉴에서 연동된 블로그 게시글을 확인할 수 있습니다
- 쇼핑몰에 게시글이 노출되기까지 **최대 10~15분 소요**됩니다

### URL 연결 안 될 시 대응
- 정상적인 주소임에도 연결 확인이 되지 않는 경우, 1:1 상담을 통해 연결을 요청할 수 있습니다

## 위젯 내 소셜 리뷰 노출 방법

### 기본 설정
- 위젯 옵션의 "소셜 연동 리뷰 설정"을 켜두면 별도의 위젯 추가 없이 연동된 소셜 리뷰가 사용 중인 위젯에 자동 게시됩니다
- 기본적으로 인스타&블로그 연동 리뷰 설정은 활성화되어 있습니다

### 위젯 설정 변경 필요한 경우
- 이전에 해당 설정을 끈 경우
- SNS 리뷰가 생성되었는데 위젯에 노출되지 않는 경우
- 특정 위젯에서는 SNS 리뷰를 노출하고 싶지 않은 경우

위젯 설정에서 소셜 연동 리뷰 옵션을 확인하거나 변경할 수 있습니다.

## 소셜 리뷰 연동 가능 위젯

다음 위젯들에서 SNS 리뷰를 노출할 수 있습니다:

- 스토리
- 베스트리뷰
- 베스트 텍스트리뷰
- 스마트픽
- 심플포토
- SNS
- 포토리뷰
- 상품별 리뷰목록
- 상품별 리뷰
- 상품별 리뷰 비교
- 게시판형(기본, 카페24/아임웹)
- 플로팅 위젯
