# 인스타그램 게시물 연동 가이드

## 개요

알파리뷰의 인스타그램 게시물 연동 기능을 통해 "해당 계정이 태그된 인스타그램 게시글을 자사몰 콘텐츠로 만들 수 있어요"

**접속 경로:** 리뷰 관리 > 인스타 & 네이버 블로그 > 인스타그램

---

## 주요 기능

### 인스타그램 게시글 연동

#### 기본 정보
- 최근 1년 내 계정이 태그된 게시물 중 최대 2,000개까지 연동 가능
- 게시물당 첨부된 이미지/동영상 최대 20장까지 연동
- 동영상은 썸네일 이미지로 대체되어 표시

#### 필수 요구사항
연동하기 전에:
1. "게시글 작성자의 동의를 구할 것을 권장"
2. 작성자가 원본 게시물을 삭제해도 "연동 된 리뷰는 삭제되지 않기 때문에 해당 사실을 인지시켜 주세요"

---

## 설정 방법

### 1단계: 계정 연동

**필수 조건:**
- "페이스북 비지니스 페이지에 인스타그램 프로페셔널 계정이 연동 되어있어야 합니다"
- 비즈니스 페이지 및 프로페셔널 계정이 아니면 등록 불가능

**절차:**
1. 대시보드 하단의 기본 정보 클릭
2. SNS 계정 연동 진행

**로딩 시간:**
게시물 양에 따라 1~2분 소요. 로딩 중 어드민 종료 및 페이지 이탈과 상관없이 게시물은 불려와집니다.

### 2단계: 게시물 선택 및 상품 연동

1. 연동 가능한 게시물 리스트 확인
2. 각 게시물에 상품 선택 (여러 상품 선택 가능)
3. 상품 연동 완료 시 SNS 리뷰 자동 생성

**중요 주의사항:**
"연동 시 여러 개의 상품을 선택할 수 있지만 연결 된 상품의 개수만큼 리뷰가 생성 됩니다"

예시: 1개 게시물 + 4개 상품 선택 = 총 4개의 SNS 리뷰 생성

### 3단계: 게시 확인

사이트 내 실제 노출까지 10~15분 소요

---

## 게시물 관리

### 상품 관리
- 연동 상품 삭제 시 생성된 SNS 리뷰도 함께 삭제
- 새로운 상품 선택 시 해당 상품에 SNS 리뷰 재생성

### 리뷰 관리
생성된 SNS 리뷰에 대해:
- 숨기기
- 수정
- 삭제

---

## 위젯 내 소셜 리뷰 노출

### 기본 설정
인스타&블로그 연동 리뷰 설정은 기본적으로 활성화되어 있습니다.

### 지원하는 위젯
다음 위젯에서 SNS 리뷰 노출 가능:
- 스토리
- 베스트리뷰
- 베스트 텍스트리뷰
- 스마트픽
- 심플포토
- SNS
- 포토리뷰
- 상품별 리뷰목록
- 상품별 리뷰
- 상품별 리뷰 비교
- 게시판형 (기본, 카페24/아임웹)
- 플로팅 위젯

### 설정 변경
이전에 설정을 꺼두었거나, SNS 리뷰가 특정 위젯에서 노출되지 않는 경우:
- 위젯 설정 확인 및 수정 필요

---

## 주의사항 및 제약사항

| 항목 | 내용 |
|------|------|
| 계정 인증 | 비즈니스 페이지 + 프로페셔널 계정 필수 |
| 연동 기간 | 최근 1년 이내 게시물만 가능 |
| 게시물 수 | 최대 2,000개 |
| 미디어 개수 | 게시물당 최대 20장 |
| 리뷰 생성 | 상품 선택 개수 = 생성되는 리뷰 개수 |
| 원본 삭제 | 작성자가 원본 삭제해도 연동 리뷰는 유지 |
| 동영상 처리 | 썸네일 이미지로 대체 |

---

## 자주 묻는 질문

**Q: 계정이 등록되지 않습니다.**
A: 페이스북과 인스타그램 계정 상태를 먼저 확인하고, 문제가 없으면 1:1 상담으로 문의

**Q: SNS 리뷰가 생성되었는데 위젯에 나타나지 않습니다.**
A: 위젯 설정에서 인스타&블로그 연동 리뷰 표시 옵션을 활성화했는지 확인

**Q: 1개 게시물에 여러 상품을 연동하면 어떻게 되나요?**
A: 선택한 상품 개수만큼 별도의 SNS 리뷰가 생성되며, 상품 간 리뷰 연결 기능 사용 시 중복 노출 가능
