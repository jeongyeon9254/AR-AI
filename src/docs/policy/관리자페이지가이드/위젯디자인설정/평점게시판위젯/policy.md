# 평점 위젯/게시판 위젯 가이드

## 개요

알파리뷰의 평점 위젯과 게시판 위젯에 대한 사용 방법을 설명하는 페이지입니다. 이 위젯들은 리뷰 데이터를 다양한 형태로 표시하며, 폭넓한 커스터마이징이 가능합니다.

## 1. 평점 위젯

### 기능 설명

평점 위젯은 "작성된 리뷰의 별점 평균과 리뷰 수, 설문 리뷰 답변을 요약해 보여주는" 위젯입니다. 모바일과 PC 버전 모두 지원됩니다.

### 주요 특징

- 별점 평균 표시
- 전체 리뷰 수 표시
- 설문 리뷰 답변 요약
- 평점 비율 노출 여부 자유 설정
- 설문 항목 답변 비율 노출 여부 자유 설정

### 자동 반영 기능

- 숨김 처리된 리뷰는 자동으로 평점 및 리뷰 개수에서 제외됩니다

### 디자인 설정

- 별점과 같은 테마 색상은 대시보드 > 공통 디자인에서 설정한 값이 반영됩니다
- 위젯 구조에 영향을 주지 않는 한해서 간단한 CSS 스타일 수정이 가능합니다

## 2. 게시판 위젯 (기본)

### 기능 설명

게시판 위젯은 "리뷰 종류와 상관없이 작성되어 있는 모든 리뷰가 한꺼번에 보여지는" 위젯입니다.

### 표시 옵션

- 리뷰 내용 전체 펼침 가능
- n줄까지만 미리 보여지도록 접기 가능

### 정렬 방식

기본값은 "최신순"으로 설정되어 있습니다.

### 상단 고정 기능

정성스럽게 작성된 리뷰를 다른 리뷰보다 먼저 보여주기 위해 상단 고정 기능을 사용할 수 있습니다.

### 설문 리뷰 연동

키, 몸무게 등을 리뷰로 받기 위해 설문 리뷰 기능을 활용할 수 있습니다.

## 3. 게시판 위젯 (카페24)

### 기능 설명

게시판 위젯(기본)과 "디자인만 다른 동일한 기능의 위젯"입니다. 카페24에서 제공되는 디자인과 유사하게 만들어졌습니다.

### 선택 사항

기본 위젯과 카페24 위젯 중 원하는 디자인으로 선택하거나 변경하여 사용할 수 있습니다.

### 상세 사항

작성자명, 작성 날짜 등이 보여지는 위치 및 디자인 디테일은 상이하지만, 작동 방식과 설정은 동일합니다.

## 일반 설정 및 정책

### 공통 설정 기능

모든 위젯은 다음과 같은 설정을 자유롭게 변경할 수 있습니다:
- 작성 날짜 설정
- 위젯에서 보여질 리뷰 개수 설정
- 기타 다양한 커스터마이징 옵션

### 디자인 작업 정책

알파리뷰는 다음과 같은 정책을 가지고 있습니다:

- **미지원 사항**: 쇼핑몰 스킨 내 디자인 영역의 작업(영역 생성 및 이동)
- **지원 가능**: 간단한 CSS 수정(모서리 둥글게 처리 등)
- **미지원 사항**: 위젯 구조에 영향을 주는 수정

### 디자인 수정 프로세스

레퍼런스를 전달하면 다음의 방식으로 진행됩니다:
- 가능한 영역 확인 및 안내
- 수정 작업 지원
- 추가 비용 없음
- 작업 종류에 따라 최대 5~7 영업일 소요 가능
- 1:1 상담을 통해 문의 가능
