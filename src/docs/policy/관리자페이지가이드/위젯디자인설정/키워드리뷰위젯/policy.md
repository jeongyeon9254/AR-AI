# 키워드 리뷰 위젯 가이드

## 개요

키워드 리뷰 위젯은 고객이 리뷰 작성 시 직접 선택한 키워드를 요약하여 표시하는 기능입니다.

## 주요 특징

- **자동 설치**: "기능 설정 시 자동으로 설치되므로 별도의 설치 작업은 필요하지 않습니다"
- **위치 커스터마이징**: 지정된 기본 위치가 있으며, 다른 위치에서 보여지기를 원할 경우에만 수정 작업 필요
- **실시간 반영**: 고객이 리뷰 작성 시 키워드를 선택하면 위젯에 자동으로 적용

## 기능 설명

### 키워드 표시
위젯은 고객이 선택한 키워드들을 시각적으로 정리하여 상품 리뷰 영역에 표시합니다.

### 추천 리뷰 영역
대시보드에서 특정 리뷰들을 선별하여 위젯에 노출 가능합니다.

### 대시보드 설정
작성 페이지에서 어떤 키워드를 보여줄지 대시보드에서 설정할 수 있습니다.

## 지원 버전

- PC 버전
- Mobile 버전
