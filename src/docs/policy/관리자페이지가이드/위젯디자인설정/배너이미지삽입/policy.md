# 배너 이미지/텍스트 삽입 방법

## 개요

알파리뷰의 커스텀 에디터 기능을 통해 이미지, 텍스트, 여백 등을 삽입할 수 있습니다. 리뷰 영역을 제외한 쇼핑몰의 다양한 영역에 배너와 띠배너를 추가하려면 알파 푸시의 배너 관리 기능을 활용해야 합니다(별도 앱 설치 필요).

**가이드 검색 키워드**: 배너 이미지, 이미지 삽입, 커스텀 에디터 위젯

## 주요 목적

포인트 지급 조건, 베스트 리뷰어 정보, 리뷰 작성 유도 화면 등을 텍스트와 이미지로 함께 표현하여 고객이 정보를 더 쉽게 이해할 수 있도록 돕습니다.

---

## 커스텀 에디터를 이용해 이미지 삽입하기

### 설정 방법

1. **[디자인 설정 > 위젯 세트 관리]**로 이동하여 이미지를 삽입할 영역의 수정하기 버튼 클릭
2. **+ 위젯 추가** 버튼 클릭
3. 전체 위젯 조회 후 **커스텀 에디터 위젯** 선택
4. 커스텀 에디터의 **상세 설정** 버튼 클릭
5. **이미지 삽입** 버튼을 선택하여 원하는 이미지 첨부
6. 팝업창에서 이미지 파일을 클릭한 후 이미지 넓이를 **100%로 리사이징**
7. 다시 이미지를 클릭 후 상단의 **정렬 아이콘**을 클릭하여 중앙 정렬 선택
8. 팝업창의 **저장** 버튼 클릭
9. 커스텀 에디터 위젯을 원하는 위치로 순서 변경

### 주의사항

- 베스트 리뷰 배너를 직접 만들기 어렵다면 알파리뷰 팀에서 제공하는 베스트 리뷰 배너를 활용할 수 있습니다.
- 공지사항 기능은 텍스트를 우선하여 노출하므로, 이미지 삽입이 필요한 경우 공지사항 기능 대신 커스텀 에디터 기능 사용을 권장합니다.

### PC와 모바일 이미지 크기 차별화

PC와 모바일의 이미지 크기를 따로 설정할 수 있습니다(상세 설정에서 가능).

## 커스텀 에디터를 이용해 텍스트 삽입하기

### 설정 방법

1. **[디자인 설정 > 위젯 세트 관리]**로 이동하여 텍스트를 삽입할 영역의 수정하기 버튼 클릭
2. **+ 위젯 추가** 버튼 클릭
3. 전체 위젯 조회 후 **커스텀 에디터 위젯** 선택
4. 커스텀 에디터의 **상세 설정** 버튼 클릭
5. **내용 작성란**에 원하는 텍스트 입력 후 저장
6. 커스텀 에디터 위젯을 원하는 위치로 순서 변경

### 활용 예시

포인트 지급 조건, 베스트 리뷰어 선정 기준, 리뷰 작성 유도 메시지 등의 중요 정보를 강조할 수 있습니다.

---

## 커스텀 에디터를 이용해 여백 삽입하기

### 설정 방법

1. **[디자인 설정 > 위젯 세트 관리]**로 이동하여 여백을 삽입할 영역의 수정하기 버튼 클릭
2. **+ 위젯 추가** 버튼 클릭
3. 전체 위젯 조회 후 **커스텀 에디터 위젯** 선택
4. 커스텀 에디터의 **상세 설정** 버튼 클릭
5. **내용 작성란**에서 필요한 만큼 **엔터**를 클릭한 후 저장
6. 커스텀 에디터 위젯을 원하는 위치로 순서 변경

### 활용 예시

위젯 간의 간격을 조절하여 페이지 레이아웃을 더욱 깔끔하고 읽기 좋게 구성할 수 있습니다.
