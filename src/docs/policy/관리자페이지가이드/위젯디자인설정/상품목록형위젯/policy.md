# 상품 목록형 위젯(1,2,3) 가이드

## 개요

상품 목록형 위젯은 세 가지 디자인 변형으로 제공되는 상품별 리뷰 표시 도구입니다. 모두 상품 이미지를 강조하며, 동일한 기능을 다른 레이아웃으로 제공합니다.

## 주요 기능

### 1. 상품별 리뷰 목록
- 상품 정보를 상단에, 리뷰를 하단에 배치
- 상품 이미지 클릭 시 해당 상품의 상세 페이지로 이동
- 모바일/PC 반응형 지원

### 2. 상품별 리뷰 게시판
- 상품 정보를 좌측에, 리뷰를 우측에 배치
- PC 버전에서만 좌우 레이아웃 적용
- 모바일에서는 상품별 리뷰 목록과 유사한 구조

### 3. 상품별 리뷰 비교
- 좌측에 상품 정보, 우측에 포토 리뷰 형식의 리뷰 표시
- 페이지 자동 넘김으로 여러 상품 표시 가능
- 단일 위젯으로 다중 상품 관리 가능

## 설정 옵션

모든 위젯에서 다음 설정이 가능합니다:

- 작성 날짜 필터링
- 표시할 리뷰 개수 설정
- 특정 상품 게시 지정/제외
- 페이지 자동 넘김 설정
- 최대 페이지 수 설정

## 제약사항 및 정책

### 디자인 작업
"저희 알파리뷰는 쇼핑몰 스킨 내 디자인 영역의 작업(영역 생성 및 이동)은 도와드리고 있지 않습니다."

- 단순 CSS 수정(모서리 둥글게 처리 등)은 가능
- 위젯 구조 변경은 불가능
- 레퍼런스 제공 시 가능 영역 검토 및 무료 수정 지원
- 작업 소요 기간: 최대 5~7 영업일

### 상품 이미지
- 카페24의 상품 목록 이미지가 자동 연동됨
- 판매 중단 상품도 리뷰가 있으면 표시됨
- 특정 그룹 판매 상품의 경우 위젯 설정에서 제외 가능

### 위젯 추가
여러 상품의 리뷰를 보여줄 때 각 상품마다 위젯을 추가할 필요가 없으며, 페이지 자동 넘김 기능으로 관리 가능합니다.
