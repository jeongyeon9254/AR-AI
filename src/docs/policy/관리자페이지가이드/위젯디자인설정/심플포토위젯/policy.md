# 심플포토/포토리뷰 위젯 가이드

## 개요

알파리뷰의 심플포토와 포토리뷰 위젯은 고객 리뷰 중 이미지와 텍스트를 활용하여 상품 페이지에 시각적 신뢰도를 높이는 기능입니다.

## 1. 포토리뷰 위젯

### 위젯 설명

"작성된 리뷰의 포토 이미지와 텍스트가 상품의 썸네일과 함께 보여지는" 형식의 위젯입니다.

### 지원 버전
- 모바일 버전
- PC 버전

### 주요 특징
- 포토 이미지와 텍스트 리뷰 내용을 함께 표시
- 상품 썸네일을 포함하여 시각적 맥락 제공

### 중요 주의사항

**텍스트 리뷰 제외 설정**
- 이미지나 동영상이 없는 텍스트 리뷰는 자동으로 제외됨
- 텍스트 리뷰만 존재하는 경우 위젯 설정에서 "사진이 없는 리뷰 제외" 옵션을 비활성화해야 함

**리뷰 노출 제어**
- 위젯 디자인 설정 > 위젯 세트 관리 페이지에서 특정 리뷰만 노출하도록 설정 가능

**동영상 형식 제약**
- GIF(움짜) 형식은 포토리뷰로 인식되지 않음
- 미리보기와 상세보기 창에서 재생되지 않음

## 2. 심플포토 위젯

### 위젯 설명

"작성된 리뷰의 포토 이미지만 보여지는" 형식의 위젯입니다. 이미지 클릭 시 리뷰 상세보기 창에서 전체 내용 확인 가능합니다.

### 지원 버전
- 모바일 버전
- PC 버전

### 주요 특징
- 포토/동영상 이미지만 표시
- 상품 상세페이지에 설치하여 이미지 모음 형태로 연출
- 이미지 클릭으로 상세 리뷰 조회 가능

### 설치 위치

**권장 위치**
- 상품 상세페이지 (최우선)

**선택적 위치**
- 메인 페이지
- 전체 후기 게시판
- 기타 원하는 위치

### 디자인 옵션

**썸네일 폭 설치** (기본값)
- 썸네일 폭에 맞게 설치

**와이드 설치** (선택사항)
- 페이지 전체 폭에 맞춰 와이드로 설치 가능

## 공통 설정 및 관리

### 위젯 설정 변경

모든 위젯은 다음 항목을 자유롭게 설정할 수 있습니다:
- 작성 날짜 기준 필터
- 위젯에 표시될 리뷰 개수

### 디자인 커스터마이징

**가능한 작업**
- CSS 간단 수정 (모서리 둥글게 처리 등)
- 제한적인 디자인 개선 사항

**불가능한 작업**
- 쇼핑몰 스킨 내 디자인 영역 작업 (영역 생성 및 이동)
- 위젯 구조에 영향을 주는 수정

**디자인 지원 절차**
- 레퍼런스 제출 → 1:1 상담 → 가능 영역 확인 및 수정 안내
- 추가 비용 없음
- 소요 시간: 작업 종류에 따라 최대 5~7 영업일

### 디자인 작업 안내

"쇼핑몰 스킨 내 디자인 영역의 작업은 도와드리고 있지 않아요. 디자인 수정 시 어떤 오류가 발생할지 알 수 없기 때문에 디자인 업체를 통해 부탁드립니다"

구조적 수정이 필요한 경우 공식 지원을 통해 문의하면 검토 후 가능 여부를 안내합니다.
