# 공지 사항/커스텀 에디터 위젯 가이드

## 개요

알파리뷰의 두 가지 특수 위젯에 대한 설명 및 사용 방법을 다룹니다. "모든 위젯들은 작성 날짜부터 위젯에서 보여질 리뷰 개수의 설정까지 다양한 설정을 자유롭게 변경할 수 있습니다."

## 주요 정책 및 제약사항

### 디자인 작업 범위
- **지원하지 않는 작업**: 쇼핑몰 스킨 내 디자인 영역의 생성 및 이동
- **지원하는 작업**: 간단한 CSS 수정(모서리 둥글게 처리 등)
- **불가능한 작업**: 위젯 구조에 영향을 주는 수정
- 복잡한 디자인 작업은 디자인 업체를 통해 요청 필요
- 1:1 상담을 통해 가능 영역 확인 후 지원(별도 비용 없음, 5~7영업일 소요 가능)

## 1. 공지사항 위젯

### 기능 설명

알파리뷰 대시보드 내에서 작성한 공지사항을 쇼핑몰 고객들에게 표시하는 위젯입니다.

### 주의사항

**카페24 플랫폼 공지와의 구분**
- "카페24에서 작성한 공지 내용은 위젯에 연동이 되지 않습니다."
- 위젯에 공지를 표시하려면 기본설정 > 공지사항에서 직접 작성해야 함

### 사용 방법

1. 알파리뷰 어드민 접속
2. 기본설정 > 공지사항 메뉴 이동
3. 공지사항 내용 작성
4. 상시설정으로 노출 설정
5. 작성된 공지가 자동으로 위젯에 표시됨

## 2. 커스텀 에디터 위젯

### 기능 설명

"심심한 위젯에 이미지, 텍스트, 여백을 원하는 디자인으로 추가할 수 있는 위젯"입니다.

### 주요 사용 사례

1. **이벤트 배너**: 리뷰 이벤트, 베스트 리뷰 배너 등 이미지를 간단하게 추가
2. **제목 텍스트**: 위젯 상단에 "실사용 고객의 구매 후기" 같은 제목 추가
3. **여백 조정**: 위젯과 위젯 사이에 여백 추가

### 설정 위치

알파리뷰 어드민 > 위젯관리 설정

### 기타 리소스

무료 다운로드 가능:
- **알파리뷰 베스트리뷰 배너.zip** (21,506.4KB)
- 베스트리뷰 배너가 없는 경우 무료로 다운로드하여 위젯 꾸미기 가능

## 일반 참고사항

### 위젯 설정 변경
모든 위젯의 다음 항목을 자유롭게 설정할 수 있습니다:
- 작성 날짜
- 위젯에 표시될 리뷰 개수
- 기타 디스플레이 옵션
