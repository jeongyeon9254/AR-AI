# 롤링 위젯 / 브리핑 위젯(카페24 전용) 가이드

## 개요

알파리뷰의 롤링 위젯과 브리핑 위젯은 프리미엄 위젯으로 별도의 월간 사용료가 발생합니다.

> "롤링 위젯: 1개월 사용료: 27,000원(VAT 별도)"
>
> "브리핑 위젯: 1개월 사용료: 39,000원(VAT 별도)"

무료 체험 기간에는 두 위젯 모두 무료로 제공됩니다.

## 주요 제약사항

### 플랫폼 제한
- **카페24 전용**: 롤링/브리핑 위젯은 카페24에서만 사용 가능하며, 아임웹에서는 사용할 수 없습니다.

### 설치 방법
프리미엄 위젯은 대시보드 내 프리미엄 메뉴에서 설치 요청을 남겨야 합니다.

### 디자인 수정 정책
- 알파리뷰는 쇼핑몰 스킨 내 디자인 영역의 작업(영역 생성 및 이동)을 지원하지 않습니다.
- 디자인 수정은 디자인 업체를 통해 진행해야 합니다.
- 간단한 CSS 수정(모서리 둥글게 처리 등)은 가능하며, 1:1 상담을 통해 문의할 수 있습니다(비용 무료, 최대 5~7 영업일 소요 가능).

### 결제 정책
- "서비스 이용료 월간 구독 중 프리미엄 기능 사용 시 첫 결제는 일할 계산되어 청구됨"
- 서비스 이용료를 선납한 경우, 프리미엄 기능도 함께 선납 결제로 진행됩니다.

---

## 1. 롤링 위젯

### 기능 설명
롤링 위젯은 상품 목록 하단에 리뷰들이 자동으로 롤링되며 표시되는 위젯입니다. 리뷰의 별점 평균과 리뷰 개수를 함께 제공합니다.

> "리뷰 영역으로 이동하지 않아도 상품에 작성되어있는 리뷰를 볼 수 있는 위젯"

### 권장 설치 위치
- 메인 페이지 BEST 상품 영역
- 카테고리 페이지 내 BEST 상품 영역

### 디자인 옵션
- 롤링되는 리뷰와 함께 별점 평균 및 리뷰 개수를 표시하는 방식
- 롤링 리뷰 없이 별점 평균과 리뷰 개수만 보여주는 방식
- 다양한 디자인 변형 제공 가능

### 반응형 지원
PC, 모바일(Mobile VER.) 버전 모두 지원합니다.

---

## 2. 브리핑 위젯

### 기능 설명
브리핑 위젯은 특정 조건으로 리뷰를 필터링하여 보여주는 위젯입니다.

### 필터링 옵션
- **상품 옵션 기준**: 색상, 사이즈 등 상품 옵션으로 필터링
- **설문 답변 기준**: 고객의 키, 체형, 피부타입, 견종 등 설문 리뷰 답변으로 필터링

### 활용 목적
리뷰를 확인하는 고객에게 조건에 맞는 관련 정보를 쉽게 제공할 수 있습니다.

### 반응형 지원
PC, 모바일(Mobile VER.) 버전 모두 지원합니다.

---

## 공통 설정 안내

### 위젯 설정 변경
모든 위젯은 다음과 같은 설정을 자유롭게 변경할 수 있습니다:
- 작성 날짜
- 위젯에서 보여질 리뷰 개수

"모든 위젯들은 작성 날짜부터 위젯에서 보여질 리뷰 개수의 설정까지 다양한 설정을 자유롭게 변경 하실 수 있음"
