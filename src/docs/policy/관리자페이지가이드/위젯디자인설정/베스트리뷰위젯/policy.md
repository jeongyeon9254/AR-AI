# 베스트 리뷰/베스트 텍스트 리뷰 위젯 가이드

## 개요

알파리뷰의 베스트 리뷰 및 베스트 텍스트 리뷰 위젯은 관리자가 지정한 우수 리뷰들을 자동으로 필터링하여 표시하는 기능입니다.

## 주요 기능

### 1. 베스트 리뷰 위젯

**설명**
- 관리자가 선택한 베스트 리뷰만 자동으로 표시
- 리뷰 이미지와 텍스트 모두 노출
- 모바일 및 PC 버전 지원

**사용 조건**
- 베스트 리뷰 라벨을 반드시 등록해야 함
- 라벨 등록 후 별도 설정 없이 자동 반영

### 2. 베스트 텍스트 리뷰 위젯

**설명**
- 베스트 리뷰와 동일한 라벨 시스템 사용
- 리뷰 텍스트 내용에 중점을 둔 표시
- 이미지는 미노출
- 더 많은 수의 리뷰를 텍스트로 보여줄 수 있음

**사용 시점**
- 소수의 이미지 리뷰보다 많은 양의 텍스트 리뷰 표시 원할 때 추천

## 설정 방법

### 베스트 리뷰 라벨 등록 프로세스

1. 알파리뷰 대시보드 접속
2. "리뷰 목록" 페이지에서 전체 작성 리뷰 확인
3. 노출할 리뷰의 내용 및 이미지 검토
4. 원하는 리뷰에 베스트 리뷰 라벨 등록
5. 위젯에 자동 반영

## 일반 설정 옵션

모든 위젯에서 적용 가능:
- 작성 날짜 범위 설정
- 위젯에 표시할 리뷰 개수 조정
- 기타 세부 설정 변경

## 제약사항 및 주의사항

**디자인 작업 제한사항**
- "쇼핑몰 스킨 내 디자인 영역의 작업(영역 생성 및 이동)은 지원하지 않음"
- 디자인 수정은 전문 디자인 업체를 통해 진행 필요
- 단순 CSS 수정(모서리 둥글게 처리 등)만 가능

**기술 지원**
- 위젯 구조에 영향을 주는 수정은 불가능
- 레퍼런스 제공 시 1:1 상담을 통해 검토 가능
- 작업 소요 기간: 최대 5~7 영업일
- 별도 비용 없음
