# 공지사항 설정 가이드

## 개요

공지사항 위젯은 알파리뷰의 기본 위젯으로 제공되며, 고객에게 이벤트나 운영 정책 등의 소식을 전달하는 기능입니다. 호스팅사(카페24/아임웹)의 공지사항과는 별도로 운영되므로, 알파리뷰 서비스 내에서 별도로 관리해야 합니다.

**주의**: 대시보드에서 공지사항 위젯을 삭제한 경우, 작성된 공지사항이 표시되지 않습니다. 기능 사용을 위해 위젯을 재추가해야 합니다.

---

## 공지사항 설정 방법

### 접근 경로
`기본 설정 > 공지사항 설정`

### 주요 기능
- 새로운 공지 추가
- 기존 공지 수정/삭제

---

## 공지 작성 방법

### 5단계 작성 프로세스

#### 1. 머릿말 설정
- **이벤트** 또는 **공지사항** 중 선택

#### 2. 제목
공지의 제목 작성

#### 3. 공지 내용
"텍스트 공지 권장"으로 안내되며, 이미지 삽입이 필요한 경우 커스텀 에디터 위젯 사용 권장

#### 4. 표시 위치
공지사항이 노출될 위치 선택 (반드시 1개 이상 선택):
- 자사몰 리뷰 영역
- 리뷰 작성 페이지 (작성 가능한 리뷰 목록 및 마이페이지에 표시)
- 마이페이지

**참고**: 리뷰 작성 페이지 설정 시, 공지는 작성 페이지 상단에 표시되며 클릭 시 팝업창으로 전체 내용 노출

#### 5. 기간 설정
공지사항 게시 기간 설정
- 미래 날짜/시간 설정 시 해당 시점까지 공지 미노출

---

## 고객 공지사항 노출 위치

1. **자사몰 리뷰 영역** - 위젯 내 공지사항 표시
2. **작성 가능한 리뷰 목록** (리뷰 작성 페이지 내)
3. **마이페이지** (리뷰 작성 페이지 내)

---

## 검색 키워드

- 적립금 혜택 공지
- 운영정책 공지
- 리뷰 공지
