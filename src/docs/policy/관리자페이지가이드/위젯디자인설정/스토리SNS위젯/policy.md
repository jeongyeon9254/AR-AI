# 스토리/SNS 리뷰 위젯 가이드

## 개요
알파리뷰의 스토리 및 SNS 리뷰 위젯은 고객 리뷰를 시각적으로 효과적으로 전시하는 도구입니다. "모든 위젯들은 작성 날짜부터 위젯에서 보여질 리뷰 개수의 설정까지 다양한 설정을 자유롭게 변경할 수 있습니다."

## 주요 제약사항

### 디자인 작업 정책
- 알파리뷰는 쇼핑몰 스킨 내 디자인 영역의 작업(영역 생성 및 이동)을 지원하지 않습니다
- 디자인 수정은 디자인 업체를 통해 진행해야 합니다
- 간단한 CSS 수정(모서리 둥글게 처리 등)은 가능하나, 위젯 구조에 영향을 주는 수정은 불가능합니다
- 레퍼런스 제공 시 가능 범위를 확인한 후 지원 가능하며, 최대 5~7 영업일 소요될 수 있습니다

### SNS 리뷰 위젯 제약
- "SNS 리뷰 위젯은 인스타그램, 네이버 블로그에서 연동 된 리뷰가 자동으로 필터링되어 보여지는 위젯"입니다
- SNS에서 연동된 리뷰가 없으면 위젯이 표시되지 않습니다
- 인스타그램의 기능 사용 전 작성된 리뷰는 스태프 리뷰 기능으로 수동 연동 가능합니다

---

## 1. 스토리 위젯

### 기능 설명
스토리 위젯은 "인스타그램 스토리와 디자인과 기능이 매우 흡사한 알파리뷰만의 특별한 위젯"입니다.

### 주요 특징
- 실제 인스타그램 스토리처럼 확인한 리뷰는 가장 뒤로 이동하고, 미확인 리뷰가 앞에 표시됩니다
- 상품 썸네일 또는 고객 리뷰 이미지/동영상 표시 옵션 제공
- 메인페이지: 상품 썸네일 표시 권장
- 상품 상세페이지: 고객 리뷰 이미지 표시 권장

### 설치 및 커스터마이징
- 기존 위젯 세트에 스토리 위젯만 추가하여 간단하게 사용 가능
- 다양한 전용 설정 제공
- 위젯 세트 미설치 영역에는 추가 설치 작업 필요 가능

---

## 2. SNS 리뷰 위젯

### 기능 설명
"인스타그램, 네이버 블로그에서 연동 된 리뷰만 자동으로 필터링해 보여주는 위젯"입니다.

### 사용 환경
- **모바일 버전**: 별도 최적화 레이아웃 제공
- **PC 버전**: 데스크톱 최적화 레이아웃 제공

### 설정
기본값이 설정되어 있어 별도의 추가 설정 없이 SNS 연동 리뷰가 자동으로 필터링됩니다.

### 연동 대상
- 협찬, 체험단, 인플루언서의 SNS 게시물을 쇼핑몰에 노출 가능
