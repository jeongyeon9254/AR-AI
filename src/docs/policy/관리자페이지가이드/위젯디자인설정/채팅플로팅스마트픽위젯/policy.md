# 채팅 리뷰/플로팅 리뷰/스마트픽 위젯 가이드

## 개요

알파리뷰는 세 가지 특수 위젯을 제공합니다. 모든 위젯은 작성 날짜, 노출 리뷰 개수 등 다양한 설정을 자유롭게 변경할 수 있습니다.

## 주요 안내사항

### 디자인 작업 관련
- "스킨 내 디자인 영역의 작업(영역 생성 및 이동)은 도와드리고 있지 않아요"
- 간단한 CSS 수정(모서리 둥글게 처리 등)은 가능하나, 위젯 구조에 영향을 주는 수정은 불가능
- 디자인 수정은 디자인 업체를 통해 요청 필요
- 레퍼런스 제공 시 1:1 상담으로 가능 영역 확인 가능(추가 비용 없음, 최대 5~7 영업일 소요)

### 설치 관련
- 채팅/플로팅 리뷰는 별도 위젯 세트 생성 필요
- 직접 설치 시 정상 노출되지 않을 수 있으니 1:1 상담으로 추가 설치 요청 필요

---

## 1. 스마트픽 위젯

### 기능
상품 이미지와 함께 텍스트를 강조해서 보여주는 위젯입니다.

### 동작 방식
- 별도 설정 없으면 모든 리뷰 노출
- 특수 라벨 기능으로 강조할 리뷰 선택 가능

### 지원 버전
- 모바일 버전
- PC 버전

---

## 2. 채팅 리뷰 위젯

### 기능
화면에서 올라오는 말풍선 안에서 리뷰를 표시하는 위젯입니다.

### 설정 옵션
- 몇 초 동안 몇 개의 리뷰 보여줄지 세부 설정 가능
- 기본적으로 상세 페이지 내 설치 시 현재 상품의 리뷰만 표시
- 메인페이지에 설치 시 선택한 리뷰만 노출 설정 가능

### 지원 버전
- 모바일 버전
- PC 버전

### 제약사항
- 모바일에서 플로팅 리뷰와 동시 사용 불가능(설치 위치 동일)

---

## 3. 플로팅 리뷰 위젯

### 기능
팝업창 형태로 리뷰를 보여주는 위젯입니다.

### 설치 제한
"상품의 상세페이지에만 설치가 가능한 위젯이에요"

### 디자인 타입
총 3가지 타입 제공:
- A형
- B형 (Bright)
- B형 (Dark)

### 설정
대시보드에서 디자인 자유롭게 변경 가능

### 제약사항
- 모바일에서 채팅 리뷰와 동시 사용 불가능(설치 위치 동일)
