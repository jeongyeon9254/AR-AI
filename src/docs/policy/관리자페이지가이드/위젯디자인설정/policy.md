# 위젯 디자인 설정

## 개요

### 위젯이란?

알파리뷰에서 작성된 리뷰들을 쇼핑몰에 표시하는 프로그램입니다.

- 리뷰 작성 시 알파리뷰 데이터베이스에 저장
- 어드민에서 게시 여부 결정 가능
- DB의 리뷰가 각 위젯의 특징에 맞춰 고객에게 노출
- 위젯 설치 여부는 리뷰 데이터에 영향을 주지 않음
- 위젯 세트 관리에서 표시할 리뷰, 순서, 작성 날짜, 작성자 명 등 설정 가능

### 위젯 세트란?

여러 개의 위젯이 묶여 하나의 세트가 되어있는 상태를 의미합니다.

**알파리뷰 기본 설치 시 생성되는 위젯 세트:**
- 상품 상세 리뷰 영역: 상품 상세 페이지 전용 기본 위젯 세트
- 상품 상세 심플 포토: 상품 상세 페이지 썸네일 하단의 심플포토 위젯 세트
- 상품 후기 게시판 리뷰 영역: 전체 리뷰 게시판 전용 기본 위젯 세트
- 메인페이지 리뷰 영역: 쇼핑몰 메인페이지의 리뷰 영역
- 그 외 추가 설치된 위젯 세트

## 주의사항

### ⚠️ 반드시 확인하세요

1. **위젯 세트 삭제 시 주의**
   - 기존에 알파리뷰가 생성해놓은 위젯 세트를 삭제할 경우 쇼핑몰 내에서 리뷰가 정상적으로 표시되지 않을 수 있음

2. **리뷰 영역 관리**
   - 알파리뷰는 리뷰 영역을 만들지 않음
   - 기본적으로 쇼핑몰 디자인 스킨 상의 리뷰 영역에 위젯이 대체되어 표시
   - 리뷰 영역 자체의 변경/수정은 스킨 제작업체/담당자를 통해 진행
   - 알파리뷰에서 직접 디자인 수정 시 오류 발생 가능성 및 대처 불가능

3. **특수 위젯 제약사항**
   - 프리미엄 위젯(롤링, 브리핑), 채팅 리뷰, 플로팅 리뷰는 위젯 추가 방식으로 정상 작동하지 않음
   - 별도의 위젯 세트 필요. 담당 부서 설치 작업만 가능
   - 별도 사용료/설치 비용 없음

## 위젯 세트 추가 설치

### 메뉴 위치
**디자인 설정 > 위젯 세트 관리**

### 설치 순서

1. 페이지 최하단의 "위젯 추가" 버튼 클릭
2. 담당자가 알아보기 쉬운 위젯 세트 이름으로 변경 (쇼핑몰 노출 X)
3. 사용할 위젯 종류 추가 및 설정 변경 후 저장
   - ⚠️ HTML 내 위젯 코드 삽입까지 완료해야만 쇼핑몰에 노출됨
4. 생성한 위젯 세트 코드 복사

### 쇼핑몰 디자인 HTML 내 코드 삽입

1. **PC 버전 수정**: 디자인 관리 접속
2. **모바일 버전 수정**: 모바일 쇼핑몰 관리 접속
3. 복사한 위젯 세트 코드를 원하는 위치에 붙여넣기
4. 저장

**참고**: PC/모바일 모두 노출하려면 모바일 대표 디자인에도 코드 삽입 필요.

## 위젯 추가/삭제/순서 변경

### 메뉴 위치
**디자인 설정 > 위젯 세트 관리 > 설정**

### 설정 방법

1. 어드민 > 디자인 설정 > 위젯 세트 관리 > 설정 이동
2. 수정할 위젯 세트의 "상세설정" 버튼 클릭

**위젯 추가**: "위젯 추가" 버튼 클릭 후 원하는 위젯 선택
**위젯 순서 변경**: 위젯 박스를 드래그하여 순서 변경
**위젯 삭제**: 휴지통 버튼 클릭으로 즉시 삭제

3. "저장" 버튼 클릭
4. 쇼핑몰 적용까지 최대 10~15분 소요
5. 미적용 시 브라우저 캐시/쿠키 삭제 후 확인

### 위젯 세트 삭제

위젯 세트를 삭제하려면 쇼핑몰 디자인 관리 HTML에 삽입된 위젯 코드를 직접 삭제해야 합니다. 위젯 설정 변경, 종류, 위젯 추가 등은 별도 HTML 작업 불필요.

## 위젯 옵션 수정

### 메뉴 위치
**디자인 설정 > 위젯 세트 관리 > 설정**

### 수정 가능한 정보

- 상품 정보
- 댓글
- 위젯 내 표시되는 리뷰 개수
- 작성일자
- 작성출처
- 그 외 위젯별 특성에 맞는 정보

### 게시 기준 정의

위젯에 표시될 리뷰 범위를 설정합니다:

1. **자동 게시** (기본값) — 해당 위젯이 설치된 페이지의 상품에 작성된 모든 리뷰 게시
2. **지정 리뷰 게시** — 지정된 라벨/카테고리/상품 리뷰만 게시 (⚠️ 미지정 시 노출 X)
3. **모든 리뷰 게시** — 대시보드의 모든 리뷰 게시
4. **특수 라벨 게시** — 베스트 리뷰 라벨 등 특수 라벨 리뷰만 게시

## CSS 수정 방법

운영 정책, 리뷰 정렬방식 등 위젯 내 옵션으로 미노출할 수 없는 옵션에 대해서만 CSS 수정.

자사몰 내 CSS 수정 후 대시보드에 수정 사항을 입력해야 쇼핑몰에 적용.

수정 가능한 CSS:
- `display: none;` (미노출)
- 색상 코드
- 텍스트 크기
- 라운딩 처리 등

## FAQ

### Q. 설치가 어렵습니다
알파리뷰의 1:1 문의 채널을 통해 설치 작업을 요청.

### Q. 위젯에서 보여지는 리뷰 개수를 변경하고 싶을 때는?
위젯의 가로배열/세로배열을 변경하여 조정.

### Q. 특수 위젯의 추가 설치가 어렵습니다
상담 채널을 통해 추가 설치 작업을 요청. 별도의 사용료/설치 비용 없음.
