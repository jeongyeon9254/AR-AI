# 공통 디자인 가이드

## 개요

공통 디자인 기능은 "작성자명, 리뷰 상세보기 창, 리뷰 작성 유도 메시지 등 전체 위젯에 해당하는 설정을 변경"할 수 있는 기능입니다.

**접속 경로**: 디자인 설정 > 공통 디자인

## 주의사항

- 설정 변경 후 저장 버튼을 반드시 눌러야 합니다
- 설정 변경이 쇼핑몰에 반영되려면 최대 15분이 소요될 수 있습니다
- 적용되지 않는 경우 인터넷 캐시/쿠키를 삭제해주세요

## 위젯 공통 디자인 설정

### 컬러
색상 커스터마이징 옵션

### 폰트
글꼴 설정 옵션

### 작성자 정보

#### 작성자명 표시 방식
- **ID 표시**: 고객의 아이디로 표현
  - 일반 회원가입: 회원가입 시 입력한 아이디
  - 카카오/네이버 간편가입: "카카오 로그인" 또는 "네이버 로그인" 텍스트 표시
  - 기타 간편가입: "기타 로그인" 텍스트 표시
- **고객명 표시**: 고객의 이름으로 표현
- **비회원 표시**: 비회원 고객은 설정과 무관하게 항상 "[비회원]"으로 노출됨

#### 개인정보 숨김
- 숫자 입력 시, 뒤에서부터 N자리까지 별표(*)로 처리됨
- **기본값**: 2 (예: "홍**" 형태로 표시)
- **제약**: 중간부터 선택적 별표 처리는 불가능

#### 실제 구매 여부
- "구매인증" 아이콘 표시 여부를 설정합니다
- 실제 구매자가 작성한 리뷰에만 아이콘이 표시됨
- 주문 건이 확인되지 않는 리뷰(관리자 리뷰 등)는 아이콘 미표시
