# 게시/지급 설정 가이드

## 개요

알파리뷰의 "리뷰 게시/지급 설정"은 관리자의 검수 후 리뷰가 게시되고 적립금이 지급되는 시점을 제어하는 기능입니다. 쇼핑몰의 운영 정책에 맞춰 설정을 변경할 수 있습니다.

**주요 특징:**
- 리뷰 게시 시점과 혜택 지급 시점을 독립적으로 설정 가능
- 호스팅사(카페24/아임웹) 연동 리뷰에도 동일하게 적용
- 기본 설정값은 "수동"
- 설정 변경 후 작성되는 리뷰부터 새로운 설정이 적용됨

> "외부 리뷰(호스팅사(카페24/아임웹) 등)에는 적립금이 지급되지 않습니다"

## 접속 경로

**경로:** 리뷰 목록 페이지 우측 상단 → [게시/지급 설정]

## 설정 옵션

### 리뷰 게시 설정 옵션

다음 5가지 옵션 중 선택 가능:

1. **수동 게시** - 관리자가 직접 게시 버튼을 눌러 리뷰를 게시
2. **즉시 자동 게시** - 리뷰 작성 후 바로 게시
3. **1일 후 자동 게시** - 작성 후 1일 경과 후 자동 게시
4. **3일 후 자동 게시** - 작성 후 3일 경과 후 자동 게시
5. **7일 후 자동 게시** - 작성 후 7일 경과 후 자동 게시

### 혜택 지급 설정 옵션

다음 5가지 옵션 중 선택 가능:

1. **수동 지급** - 관리자가 직접 지급 버튼을 눌러 포인트 지급
2. **즉시 자동 지급** - 리뷰 작성 후 바로 포인트 지급
3. **1일 후 자동 지급** - 작성 후 1일 경과 후 자동 지급
4. **3일 후 자동 지급** - 작성 후 3일 경과 후 자동 지급
5. **7일 후 자동 지급** - 작성 후 7일 경과 후 자동 지급

## 리뷰 게시 상태 정의

| 상태 | 설명 |
|------|------|
| **리뷰 게시** | 수동 게시 설정 시 리뷰 등록 상태. 게시 전까지 쇼핑몰에 노출 안 됨 |
| **n일 후 게시** | n일 후 자동 게시로 설정된 상태. n일 후 자동으로 게시 예정 |
| **게시전 확인 필요** | 리뷰 게시 정책(별점, 이미지 포함 여부 등)에 의해 검수 필요. 수동 게시 필요 |
| **게시 완료** | 자동 게시 완료 또는 수동으로 게시된 상태. 현재 쇼핑몰에 노출 중 |
| **게시 취소** | 게시된 리뷰를 관리자가 숨김 처리한 상태. 별점 평가에서 제외됨 |

**처리 소요 시간:**
- "수/자동 게시 모두 실제로 자사몰 내에 리뷰가 보여지기까지 최대 1~5분 소요"

## 리뷰 혜택 지급 상태 정의

| 상태 | 설명 |
|------|------|
| **n포인트 지급** | 수동 지급 설정 시. 지급할 포인트 표시, 버튼 클릭으로 수동 지급 |
| **n포인트 지급 완료** | 호스팅사를 통해 고객에게 적립금 지급 완료. 회수 버튼으로 회수 가능 |
| **n포인트 회수** | 적립금 회수 완료 상태 |
| **회원가입 시 지급** | 비회원이 작성한 리뷰. 고객 회원가입 후 최종 지급 |
| **지급 제한** | 리뷰/혜택 정책으로 인해 지급 제한된 상태 |
| **지급 포인트 없음** | 리뷰는 작성했으나 포인트 지급 대상이 아닌 경우 |
| **지급 예정** | 검수 완료. 수십 분 내 지급 예정 |
| **n일 뒤 지급** | n일 후 자동 지급 설정. n일 후 자동으로 지급 예정 |
| **지급 전 확인 필요** | 지급 정책(별점, 이미지 포함 여부 등)에 의해 검수 필요. 수동 지급 필요 |
| **지급 취소** | 관리자가 지급 전 취소한 상태. 시스템상 지급 전 단계에서만 가능 |

**처리 소요 시간:**
- "수/자동 지급 모두 실제로 고객에게 지급되기까지 최소 1일 소요"

## 설정 변경 시 주의사항

- 설정 변경 후 새롭게 작성되는 리뷰부터 새로운 설정값이 적용됨
- 수동 게시/지급 설정 시 작성된 리뷰의 검수 값은 설정 변경 후에도 유지됨
- 설정 변경 전 작성된 리뷰는 별도 처리 필요

## 일괄 처리 기능

### 개요

리뷰 좌측의 체크박스를 클릭하면 선택된 리뷰들에 대해 다음 작업을 일괄 처리할 수 있습니다:

- 상단 고정
- 하단 고정
- 게시
- 숨김 처리
- 혜택 지급
- 확인
- 삭제

### 일괄 지급 시 제약사항

> "일괄처리의 혜택 지급은 시스템이 자동 계산한 혜택만 적용"

수동으로 추가 지급할 포인트가 필요한 경우, 각 리뷰의 "포인트 관리" 버튼을 통해 개별 지급해야 합니다.

## 키워드 필터링

특정 단어를 별표(*) 표시로 자동 필터링하려면 [키워드 알림/필터 가이드](https://guide.alph.kr/d4d830e9-3e67-4b26-b813-8f95f1722afd)를 참고하세요.

## 예외 사항

체크된 예외 조건(별점 n점 이하, 이미지 포함 리뷰 등)에 해당하는 리뷰는 설정과 무관하게 수동으로 게시/지급됩니다.
