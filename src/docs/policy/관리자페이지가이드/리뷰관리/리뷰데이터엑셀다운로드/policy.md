# 리뷰 데이터 엑셀 다운로드 매뉴얼

## 개요

알파리뷰 대시보드에서 리뷰 데이터를 요청하여 엑셀 파일로 다운로드할 수 있습니다.

### 주요 특징
- **데이터 유효 기간**: 다운로드 시점부터 7일
- **처리 시간**: 평균 3~4시간 (데이터량에 따라 더 소요될 수 있음)
- **파일 암호화**: 필수 (개인정보보호 법규 준수)

---

## 리뷰 데이터 요청 방법

### 1단계: 엑셀 다운로드 버튼 클릭

리뷰 목록 메뉴 우측 상단의 "[엑셀 다운로드]" 버튼을 클릭합니다.
- 대시보드 접속 시 기본으로 표시되는 페이지가 "리뷰 목록"입니다.

### 2단계: 데이터 설정 및 요청

다음 정보를 입력하고 "[다운로드]" 버튼을 클릭합니다:

#### 필수 입력 사항

| 항목 | 설명 |
|------|------|
| **기간 지정** | 6개월 이내의 기간만 선택 가능 |
| **필요 데이터** | 현재 대시보드에서 요청 가능한 항목만 선택 |
| **파일 비밀번호** | 영문 대소문자/숫자/특수문자(!@#$%^\*) 중 두 가지 이상 조합, 10~16자리 필수 |
| **수신 이메일** | 데이터를 받을 이메일 주소 |

#### 주의사항
- "요청을 삭제하면 다운로드 보관함에서 확인할 수 없습니다"
- "엑셀 파일 요청 후에는 이메일 주소 등 정보를 변경할 수 없습니다"

### 6개월 이상 데이터 필요 시

예시: 2023년 전체 데이터 필요
1. **첫 번째 요청**: 2023.01.01 ~ 2023.05.31
2. **두 번째 요청**: 2023.06.01 ~ 2023.12.31

총 2회 신청 필요합니다.

### 3단계: 다운로드 링크 확인

#### 확인 방법
- 대시보드 하단 "[다운로드 내역 보기]"에서 확인
- 입력한 이메일 주소 수신함에서 확인

#### 다운로드 유효 기간
- 이메일 수신 후 7일 이내에 다운로드 필요
- 기간 경과 시 재신청 필요

---

## 파일 암호화 정책

### 비밀번호 설정 규칙

"영문 대소문자/숫자/특수 문자(!@#$%^\*) 중 두가지 이상 조합으로 10자리~16자리를 필수로 입력해야" 합니다.

### 법적 근거

"방송통신위원회가 고시한 '개인 정보의 기술적/관리적 보호조치 기준' 에 근거해 개인정보를 PC에 저장할때에는 의무적으로 암호화"해야 합니다.

### 비밀번호 관리
- 알파리뷰 시스템에서는 비밀번호를 확인할 수 없습니다
- 담당자가 반드시 기억하고 있어야 합니다

## FAQ 및 주의사항

| 질문 | 답변 |
|------|------|
| **데이터 처리 시간이 오래 걸리는 이유** | 다운로드될 데이터를 임의로 확인하기 어려워 시간 경과를 기다려야 합니다 |
| **요청 후 정보 수정 가능?** | 아니요, 요청 후에는 변경 불가능하므로 사전에 충분히 확인하세요 |
| **6개월 이상의 데이터를 원할 때** | 6개월씩 나누어 여러 번 신청해야 합니다 |
| **유효 기간 경과 후** | 재신청하여 새로운 파일을 받아야 합니다 |
