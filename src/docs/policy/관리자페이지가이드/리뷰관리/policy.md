# 리뷰 관리

## 개요

알파리뷰의 리뷰 관리 기능에 대한 종합 가이드입니다. 리뷰 목록 페이지 사용법, 게시/지급 설정, 데이터 엑셀 다운로드 등 세 가지 주요 섹션으로 구성됩니다.

## 주요 기능 섹션

### 1. 리뷰 목록 페이지 가이드
관리자 페이지에서 수집된 모든 리뷰를 열람하고 관리할 수 있는 페이지입니다.

### 2. 게시/지급 설정 가이드
리뷰의 게시 여부 및 포인트 지급 설정을 관리하는 방법을 다룹니다.

### 3. 리뷰 데이터 엑셀 다운로드 매뉴얼
수집된 리뷰 데이터를 엑셀 형식으로 내보내는 기능입니다.
