# 리뷰 목록 페이지 가이드

## 개요

알파리뷰 DB에 저장된 모든 리뷰 데이터를 조회, 관리할 수 있는 핵심 관리 페이지입니다. "리뷰 조회, 관리, 적립금 지급 등 리뷰 목록 설정"을 다룹니다.

### 주요 기능
- 다양한 방식의 리뷰 조회
- 게시/숨기기/상단 고정 등 리뷰 관리
- 혜택(포인트) 적립금 수동 지급/취소/회수

---

## 리뷰 조회 방법

### 조회 기간 설정 및 검색
- 최초 접속 시 최근 3개월 리뷰만 표시
- 리뷰 작성 기간, 고객 정보, 리뷰 내용 등으로 필터링 가능
- 특정 날짜 또는 기간 선택 후 조회

### 스마트 필터
"조회 기간 아래의 체크 박스를 함께 사용하시면 n일 부터 n일 까지 작성 된 포토 리뷰만을 조회하는 등 다양한 방식으로 원하는 리뷰를 조회"할 수 있습니다.

### 상품/북마크별 조회
- **상품으로 검색**: 특정 상품의 리뷰만 필터링
- **북마크로 검색**: 북마크된 리뷰 모아보기

#### 베스트 리뷰 북마크
베스트 리뷰 북마크는 베스트 리뷰 위젯과 연동되어 별도 설정 없이 선정된 베스트 리뷰를 자동 노출합니다.

### 고급필터
- **필터 조건 수정**: 필터 상세 버튼으로 필터링 조건 선택
- **필터 조건 삭제**: X 버튼 또는 필터 초기화로 삭제
- 복수의 필터 동시 사용 가능

### 추가 조회 기능
- **고객/주문 정보 조회**: 구매자 정보 확인
- **구매 상품 페이지 확인**: 해당 상품 페이지 링크
- **포인트 관리/작성 기록**: 포인트 지급 내역 및 수정 기록 조회

### 상태별 리뷰 조회

| 상태 | 설명 |
|------|------|
| **전체** | 자사몰, 호스팅사(카페24/아임웹), 스마트스토어, SNS 연동 리뷰 모두 |
| **지급 대기** | 포인트가 아직 지급되지 않은 리뷰 |
| **지급 제한** | 포인트 지급 설정에 의해 제한된 리뷰 |
| **게시 대기** | 자사몰에 게시되지 않은 리뷰 |
| **키워드 알림** | 설정된 알림 키워드가 포함된 리뷰 |
| **댓글없음** | 관리자 댓글이 작성되지 않은 리뷰 |
| **수정 된 리뷰** | 고객 또는 관리자가 수정한 리뷰 |

#### 수정된 리뷰 주의사항
"시스템은 혜택(포인트) 지급이 완료 된 리뷰는 재검수하지 않습니다"이므로, 추가 포인트 지급이 필요하면 수동으로 처리해야 합니다.

## 리뷰 관리

### 게시/숨기기/상단 고정 설정

#### 자동 설정 변경
"포인트 자동 지급/리뷰 자동 게시 상태로 사용하고 싶으시다면 리뷰 목록 우측 상단의 게시/지급 설정에서 설정 값을 자동으로 변경해주세요!"

기본값: 모두 수동

### 리뷰 관리 도구

각 리뷰의 우측 메뉴에서 다음 기능 제공:

#### 리뷰 상태 관리
- **리뷰 게시 상태**: 게시/숨김 토글
- **포인트 지급 상태**: 지급/미지급 관리
- **상단 고정/하단 배치**: 위젯 내 노출 순서 조정
- **게시 순위 지정**: 원하는 순서대로 정렬

#### 리뷰 마킹
- **북마크**: 특정 리뷰 표시 (베스트 리뷰 등)
- **리뷰 뱃지 설정**: 인증 구매, 포토 리뷰 등 뱃지 부여

#### 리뷰 편집
- **리뷰 수정**: 콘텐츠 수정
- **리뷰 삭제**: 관리자/연동 리뷰만 삭제 가능 (고객 작성 리뷰 불가)
- **리뷰 복사**: 동일 콘텐츠를 다른 상품에 복사

#### 기타 관리
- **메모**: 내부 관리용 메모 추가
- **상품 변경(이동)**: A 상품 리뷰를 B 상품으로 이동
- **일괄처리**: 여러 리뷰를 한 번에 처리

#### 복사 vs 상품 간 연결
"리뷰 복사 기능을 사용하면 동일한 내용의 리뷰가 2개 이상 생기게 돼요"이므로, 비슷한 상품 간 리뷰 공유는 상품 간 리뷰 연결 기능 사용을 권장합니다.

### 댓글 관리

#### 자동 댓글
- **활성화 시**: 미리 작성된 댓글 표시, 답변 버튼으로 수정 가능
- **비활성화 시**: 빈칸에 수동으로 댓글 작성

#### 댓글 템플릿
댓글 템플릿을 생성하여 반복되는 댓글을 빠르게 작성할 수 있습니다.

#### 댓글 삭제 시 주의사항
"별도의 댓글 영역이 존재하므로, 댓글 내용을 삭제하더라도 빈 영역이 남게 됩니다". 위젯에서 댓글을 비활성화하려면 위젯 설정에서 별도 처리 필요합니다.

### 일괄처리

리뷰 테이블 좌측 체크박스로 선택하여 다음 작업 일괄 처리:
- 리뷰 게시
- 포인트 지급
- 리뷰 숨김
- 상단 고정/하단 배치
- 상품 변경 (이동)
- 리뷰 복사
- 리뷰 제거 (삭제)

---

## 혜택(포인트) 관리

### 포인트 지급 방식 및 제약

#### 지급 대상
"알파리뷰 어드민(대시보드)에서는 알파리뷰를 통해 작성 된 리뷰에만 포인트를 지급 할 수 있습니다"

#### 호스팅사 연동 리뷰
호스팅사(카페24/아임웹)에서 이관/연동된 리뷰는 알파리뷰에서 포인트 지급 불가능하며, 해당 호스팅사에서 직접 지급해야 합니다.

### 포인트 관리 UI

리뷰 우측의 **포인트 관리** 섹션에서:
- 포인트 지급 내역 확인
- 지급 취소
- 지급 회수
- 추가 포인트 수동 지급

### 포인트 수동 지급/취소/회수

#### 지급 금액 수정 불가
"리뷰 작성 시 혜택(포인트)는 설정 값에 따라 자동으로 계산되고, 지급액을 임의로 수정하는 것은 불가능합니다"

#### 수동 처리 방법
원하는 금액을 지급하려면:
1. 기존 포인트 지급 전부 취소
2. 새로운 금액을 수동으로 입력하여 지급

#### 추가 지급 필요 시
리뷰 수정/추가 작성으로 인한 추가 포인트는 수동으로 지급해야 합니다.

## 위젯 연동 주의사항

### 위젯 기반 노출
"리뷰 목록 페이지의 게시/숨김/상하단고정 등의 리뷰 설정은 쇼핑몰에 설치 된 위젯 내에서만 적용됩니다"

### 리뉴얼 시 재설치
쇼핑몰 리뉴얼로 위젯이 노출되지 않으면 설정이 적용되지 않은 것처럼 보일 수 있습니다. 위젯 재설치가 필요하거나 상담 채널을 통해 요청할 수 있습니다.

### 위젯 내 리뷰 표시
"쇼핑몰의 위젯 내에서는 현재 "게시" 상태의 리뷰들만 보여지므로 실제 작성 된 리뷰 개수와 상이할 수 있습니다". 총 리뷰 수는 대시보드에서 확인해야 합니다.

## 리뷰 삭제 정책

- **관리자 작성/연동 리뷰**: 삭제 가능
- **고객 작성 리뷰**: 삭제 불가능
