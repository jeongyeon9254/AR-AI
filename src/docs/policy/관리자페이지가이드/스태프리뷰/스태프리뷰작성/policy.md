# 스태프 리뷰 작성 가이드

## 개요
스태프 리뷰(관리자 리뷰)는 호스팅사와 연동되지 않는 제3플랫폼의 리뷰를 입력하기 위한 기능입니다. 어뷰징 목적이 아닌 정당한 리뷰 관리를 위해 설계되었습니다.

## 주요 정책 및 제약사항

### 기본 정책
- **용도**: 카페24/아임웹과 연동되지 않는 외부 플랫폼 리뷰 입력용
- **호스팅사 연동**: 알파리뷰 서비스 이용 중에는 호스팅사로 연동되지 않으며, 해지 시점에 일괄 이관됩니다
- **외부 플랫폼 미지원**: 현재 네이버 쇼핑 등 외부 플랫폼으로의 리뷰 개수 연동 기능은 미제공

### 시간 요구사항
- 홈페이지 표시: 10~15분 소요
- 리뷰 개수 연동: 최소 1시간 이상, 최대 3~4시간 소요
- 신규 상품 연동: 카페24 상품 생성 후 최대 3~4시간 소요

### 수정 불가능 항목
"작성 후 작성일자, 작성자 명, 상품 옵션의 수정이 불가능"합니다. 해당 정보 수정이 필요한 경우 삭제 후 재작성해야 합니다.

### 첨부 파일 제한
- 동영상: 최대 500MB 이하의 MP4 파일 1개까지만 첨부 가능

### 네이버 쇼핑 주의사항
네이버 입점 쇼핑몰의 경우, 판매량에 비해 지나치게 많은 리뷰가 작성되면 불이익을 받을 수 있으므로 주의가 필요합니다.

## 스태프 리뷰 작성 방법

### 접속 경로
리뷰 관리 > 스태프 리뷰

### 작성 단계

**1단계: 상품 선택**
- 관리자 리뷰를 작성할 상품 우측의 리뷰 작성 버튼 클릭

**2단계: 리뷰 작성**
- 리뷰 종류 선택
- 주문자 정보 입력 (옵션 사항)
- 리뷰 내용 작성
- 우측 상단의 리뷰 등록 버튼 클릭

**3단계: 완료**
- 대시보드 하단에 완료 팝업 표시

### 리뷰 종류 및 기본값

**리뷰 종류**
- 일반 리뷰: 알파리뷰 내에서 작성된 리뷰
- 인스타그램리뷰: 인스타그램을 통해 연동된 리뷰

**기본 설정 항목**
- **주문자 이름**: 입력하지 않으면 랜덤으로 자동 작성
- **주문자 ID**: 미입력 시 비회원 리뷰로 작성
- **작성 일자**: 미입력 시 리뷰 생성 당일 날짜 자동 입력

### 대량 업로드
다수의 리뷰를 업로드할 경우 [리뷰 대량 업로드] 기능 사용 권장

## 스태프 리뷰 수정/삭제 방법

### 접속 경로
리뷰 목록 > 리뷰 우측 톱니바퀴 아이콘

### 수정 가능 항목
- 별점, 작성일자, 작성자명 **제외**한 모든 항목
- 리뷰 내용, 이미지, 동영상 수정 가능

### 삭제 정책
- **삭제 가능**: 관리자 리뷰, 미검증 리뷰, 호스팅사 연동 리뷰
- **삭제 불가**: 고객이 작성한 리뷰는 임의 삭제 불가능
