# 스태프 리뷰

## 개요

스태프 리뷰는 관리자가 직접 상품에 대한 리뷰를 작성할 수 있는 기능입니다. 제3 플랫폼의 리뷰를 수동으로 입력하거나 관리 목적으로 활용됩니다.

## 주요 주의사항

### 목적 및 용도
- **허용 용도**: 호스팅사(카페24/아임웹) 연동이 되지 않는 제3 플랫폼 리뷰 입력
- **금지 용도**: 어뷰징(고객 기만) 목적 사용 금지

### 네이버 쇼핑 입점 시 주의
판매량에 비해 지나치게 많은 리뷰가 작성되면 네이버 측에서 불이익을 줄 수 있으니 주의 필요.

### 호스팅사 연동 정책
- 알파리뷰 서비스 이용 중에는 관리자 리뷰가 호스팅사로 연동되지 않음
- 서비스 해지 시점에 일괄 이관됨
- 네이버 쇼핑 등 외부 플랫폼으로의 리뷰 개수 연동 기능 미지원

## 기술 사양 및 제약

### 반영 시간
- 홈페이지 표시: 10-15분 소요
- 리뷰 개수 연동: 최소 1시간 이상 소요

### 작성일자 정책
시스템 제공 작성일자는 일반적으로 1-2주 전 날짜이므로, 최신순 정렬 시 뒷쪽에서 리뷰가 표시될 수 있음.

### 수정 불가 항목
관리자 리뷰 작성 후 다음 항목은 수정 불가능:
- 작성일자
- 작성자 명
- 상품 옵션

변경 필요 시 삭제 후 재작성 필요.

### 미디어 첨부 제한
- 동영상: 최대 500MB 이하 MP4 파일 1개까지만 가능

## 작성 방법

### 1개씩 등록 (개별 작성)
별도의 가이드 페이지에서 상세 설명 제공.

### 대량 업로드
일괄 등록 기능으로 여러 리뷰를 한 번에 업로드 가능.

## 추가 기능 및 관련 설정

### 포인트 지급
관리자 리뷰 작성 시 포인트 지급 설정 가능.

### 리뷰 관리
- 리뷰 목록 조회 및 관리
- 베스트 리뷰 선정
- 리뷰 상하단 고정/게시 순위 지정
- 지정 리뷰 표시 기능

### 위젯 설정
작성된 리뷰를 다양한 위젯 형태로 홈페이지에 표시.
