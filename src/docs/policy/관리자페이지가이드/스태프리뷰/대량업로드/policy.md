# 대량 업로드 가이드

## 개요

알파리뷰의 대량 업로드 기능을 통해 관리자가 엑셀 파일을 이용해 여러 건의 리뷰를 한 번에 등록할 수 있습니다.

## 접근 경로

**[리뷰 관리 > 스태프 리뷰 > 리뷰 대량 업로드]**

## 필수 사전 확인 사항

### 기능 목적 및 제한사항

- 이 기능은 호스팅사(카페24/아임웹)와 연동되지 않는 제3플랫폼에서 작성된 리뷰를 입력하기 위해 설계되었습니다
- "고객 기만 목적이 아닌" 별도 채널의 리뷰만 등록해야 합니다

### 네이버 쇼핑 입점사 주의사항

네이버 쇼핑 입점 중인 경우, 판매량 대비 비정상적으로 많은 리뷰가 작성되면 플랫폼 측에서 불이익을 줄 수 있습니다

### 호스팅사 연동 정책

- 알파리뷰 이용 중에는 관리자 리뷰가 호스팅사로 연동되지 않습니다
- 서비스 해지 시점에 일괄 이관됩니다
- 네이버 쇼핑 등 외부 플랫폼으로의 리뷰 개수 연동 기능은 제공되지 않습니다

### 리뷰 반영 시간

- 홈페이지 상 표시: 10~15분 소요
- 리뷰 개수 반영: 최소 1시간 이상, 최대 3~4시간 소요

### 작성일자 정책

"시스템에서 제공된 작성일자는 일반적으로 1-2주 전의 일자"이므로, 최신순 정렬 시 뒷쪽에 표시될 수 있습니다

### 수정/삭제 제약사항

관리자 리뷰는 작성 후 다음 항목의 수정이 불가능합니다:
- 작성일자
- 작성자 명
- 상품 옵션

수정이 필요하면 삭제 후 재작성해야 합니다

### 미디어 첨부 제한

동영상은 최대 500MB 이하의 MP4 파일 1개까지만 첨부 가능합니다

## 대량 리뷰 업로드 절차

### 1단계: 양식 다운로드

리뷰 작성 페이지 우측 상단의 **[리뷰 대량 업로드]** 버튼을 클릭합니다

**[엑셀 양식을 다운로드]** 텍스트를 클릭하여 양식을 받습니다

**필수사항**: "반드시 대시보드 내에서 제공되는 양식으로 파일을 업로드"해야 합니다

### 2단계: 양식 작성

다운로드한 엑셀 양식에 필요한 정보를 기입합니다

#### 입력 요구사항

- 모든 필수 항목은 반드시 입력해야 합니다
- 공백이 있으면 업로드되지 않습니다
- 리뷰 번호가 중복되면 업로드되지 않습니다

#### 이미지/동영상 입력

포토 및 동영상 리뷰는 URL 주소를 직접 입력해야 합니다

알파리뷰는 "별도의 이미지 및 동영상의 URL 추출 기능을 제공해드리고 있지 않아요"

### 3단계: 파일 저장

다운로드받은 파일에 내용을 작성 후 그대로 저장하면 xlsx 형식으로 저장됩니다

**필수사항**: "반드시 엑셀 파일로 다운 받아 업로드" (한셀 불가)

### 4단계: 파일 업로드

**[업로드]** 텍스트를 클릭하여 파일을 선택합니다

#### 파일 업로드 제한사항

- 업로드 횟수는 제한이 없습니다
- 1개 파일에는 최대 100개의 리뷰만 작성 가능합니다
- 100개 이상 업로드 시 100개씩 나누어 여러 번 업로드합니다

### 5단계: 최종 업로드

**[리뷰 업로드]** 버튼을 누르면 최종 업로드됩니다

#### 부분 업로드 정책

"파일에 작성되어있는 리뷰 중 업로드가 불가능한 리뷰가 있다면, 리뷰 업로드 시 해당 리뷰를 제외한 리뷰만 업로드 됩니다"

### 6단계: 완료 확인

대시보드 하단에 완료 팝업이 표시됩니다

"업로드된 리뷰가 홈페이지 상 표시되는데에는 최대 15~30분, 리뷰 개수가 연동되는데에는 최소 1시간, 최대 3~4시간 소요 됩니다"

## 관리자 리뷰 수정/삭제

**접근 경로**: [리뷰 목록 > 리뷰 우측 톱니바퀴]

리뷰 우측의 톱니바퀴 아이콘을 클릭하여 다음 기능을 사용할 수 있습니다:
- 리뷰 내용 수정
- 리뷰 삭제

### 수정 불가 항목

별점, 작성일자, 작성자명은 수정할 수 없습니다. 이들을 변경하려면 리뷰 삭제 후 재작성해야 합니다

### 삭제 권한

- **삭제 가능**: 관리자 리뷰, 미검증 리뷰, 호스팅사(카페24/아임웹)에서 연동된 리뷰
- **삭제 불가**: 고객이 작성한 리뷰 (임의 삭제 불가)

## 관리자 리뷰 작성 방법 (개별 등록)

개별 리뷰 등록 방법은 별도의 가이드 페이지에서 다룹니다.
