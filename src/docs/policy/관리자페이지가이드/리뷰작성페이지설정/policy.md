# 리뷰 작성 페이지 설정

## 개요

알파리뷰 서비스 이용 시 자사몰 내의 모든 리뷰 작성 경로는 알파리뷰의 리뷰 작성페이지로 자동 우회됩니다. 대시보드 내에서 제공되는 설정 값 이외의 커스텀 기능은 현재 지원되지 않습니다.

## 리뷰 작성 화면 설정 방법

### 설정 가능한 항목

리뷰 작성 페이지에서 다음 요소를 커스터마이징할 수 있습니다:

1. **별점 및 포인트 컬러**: 별점 표시 색상과 포인트 관련 색상 설정
2. **포인트 안내**: 고객에게 표시할 포인트 정보 메시지
3. **리뷰 순서 설정**: 리뷰 작성 단계 순서

## 전화번호 로그인 페이지

### 정의
자사몰 회원이 아니거나 로그인 상태가 아닌 경우 노출되는 페이지. 고객 정보 확인을 위해 필요.

### 커스터마이징 옵션

1. **메인 이미지 설정**: 페이지 상단 배너 또는 대표 이미지 변경
2. **메시지 설정**: 고객에게 표시할 안내 메시지 작성

## 알파리뷰 리뷰 작성 페이지 접속 방법

### 1. 알림톡 경로

**빠른 리뷰 사용 시**: 알림톡 내 "만족", "보통", "별로" 버튼 클릭 시 빠른 리뷰 작성과 동시에 자동으로 리뷰 작성 페이지로 이동.

**빠른 리뷰 미사용 시**: 알림톡 하단의 "리뷰 작성하기" 버튼 클릭 시 이동.

알림톡은 고객을 특정하여 발송되므로, 페이지 접속 시 별도의 로그인 절차 없이 리뷰 작성페이지로 바로 진입.

### 2. 자사몰의 위젯 경로

게시판 위젯 또는 평점 위젯 사용 시 자사몰의 리뷰 영역에 "리뷰 작성하기" 버튼 설치. 클릭 시 리뷰 작성 페이지로 이동.

**주의**: 자사몰 회원이 아니거나 미로그인 상태인 경우, 전화번호 로그인 페이지가 먼저 노출.

### 3. 대시보드 링크 및 QR 코드

**접근 경로**: `대시보드 > 디자인 설정 > 리뷰 작성 유도 > 송장 QR 코드 페이지`

페이지 최하단에서 확인 가능:
- QR 코드
- URL 주소

**특징**: URL 링크로 접속 시 고객 정보를 특정할 수 없으므로 전화번호 로그인 페이지가 노출.

## 사용 TIP

- 고객이 리뷰 작성 페이지를 찾을 수 없는 경우: 대시보드에서 작성 페이지 링크 복사 → 고객에게 직접 전달
- QR 코드/링크는 특정 템플릿 없이 제공되므로 자유롭게 활용 가능 (송장 인쇄, SNS 공유 등)

## 테스트 방법

알림톡 테스트 기능은 현재 제공되지 않습니다. 고객과 동일한 리뷰 작성 페이지를 확인하려면:

1. 리뷰 요청 기능을 사용하여 임의의 주문 건 생성
2. 해당 주문에 대해 실제 리뷰 작성 수행
3. 리뷰 작성 프로세스 및 페이지 확인
