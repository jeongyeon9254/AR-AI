# 리뷰 뱃지 사용 방법 가이드

## 개요

리뷰 뱃지 기능은 "게시판 위젯"과 "리뷰 상세보기 창"에서만 노출되는 기능입니다. 리뷰 앞에 `[BEST REVIEW]`, `[쇼핑몰 추천 리뷰]` 같은 텍스트를 붙여 리뷰의 신뢰도를 높일 수 있습니다.

**접속 경로:** [리뷰 관리 > 리뷰 뱃지]

---

## 기본 사항

### 주요 제약사항

- **최대 개수**: 1개 리뷰당 최대 3개의 뱃지까지 지정 가능
- **디자인 일괄 변경**: 뱃지 디자인 수정 시 해당 뱃지로 지정된 모든 리뷰의 뱃지 디자인도 일괄 변경
- **삭제 불가복구**: 뱃지 삭제 시 해당 뱃지로 지정된 모든 리뷰의 뱃지가 삭제되며 복구 불가능
- **비활성화 영향**: 뱃지 비활성화 시 기존 리뷰의 뱃지가 미노출되고, 자동 지정 조건에 해당하는 모든 리뷰에 일괄 적용
- **과거 리뷰 적용**: 뱃지 생성/활성화 시 이전 리뷰에 일괄 지정 가능 (최근 1년 동안 작성된 리뷰 중 최대 30,000개까지만 지정)

---

## 기본 제공 뱃지 템플릿

모든 기본 템플릿 뱃지는 **자동 지정 조건**으로 생성되며, **색상 디자인만 변경 가능**합니다.

| 뱃지명 | 자동 지정 조건 |
|--------|------------------|
| **쇼핑몰 추천 리뷰** | 리뷰 상단 고정 시 자동 지정 |
| **한달사용기** | 주문일로부터 30일 이후 작성된 리뷰 |
| **MD's Review** | 스태프 리뷰 작성 기능으로 작성된 리뷰 |
| **BEST** | "베스트 리뷰" 북마크가 지정된 리뷰 |
| **NEW** | 오늘부터 3일 이내 작성된 리뷰 |
| **재구매** | 동일 상품을 2회 이상 구매한 고객이 작성한 리뷰 |

### 재구매 뱃지 주의사항

- 알파리뷰 사용 시점 이후부터 2회 이상 구매한 경우만 지정
- 네이버 페이 등 고객 정보를 확인할 수 없는 리뷰에는 등록 불가

---

## 새로운 뱃지 등록하기

### 등록 단계

1. **뱃지 이름(필수)**: 위젯에서 고객에게 보여질 이름 입력
2. **뱃지 설명(선택)**: 관리자 구분용 설명 작성 (고객 미노출)
3. **디자인 설정(필수)**: 위젯에서 고객에게 보여질 색상 선택
4. **조건 설정**: 자동 지정 뱃지 생성 시에만 조건 설정 (수동 뱃지는 디자인 설정까지만)
5. **과거 리뷰 적용 선택**: 뱃지 등록 후 이전 리뷰에도 적용할지 선택

### 자동 조건 설정 시 주의사항

- **수정 불가**: 자동 지정 조건은 뱃지 생성 후 수정 불가능
- **AND 조건 적용**: 여러 조건 설정 시 모두 충족되는 리뷰에 지정
  - 예: "상단 고정된 리뷰" AND "재구매 고객 리뷰"에 모두 뱃지 지정

---

## 뱃지 수동 지정 방법

자동 지정 조건을 설정하지 않은 뱃지는 수동으로만 등록합니다.

### 사용 사례

- 관리자가 리뷰 내용을 직접 확인 후 뱃지 등록하고 싶을 때
- 자동 지정 조건에 부합하지는 않지만 뱃지를 등록하고 싶을 때

### 등록 절차

1. **[리뷰 목록]** 페이지 접속
2. 리뷰 내용 상단의 뱃지 아이콘 클릭
3. 현재 활성화된 뱃지 목록에서 원하는 뱃지 클릭으로 리뷰에 등록

### 필수 조건

**뱃지를 수동으로 등록하려면 반드시 뱃지가 활성화되어 있어야 합니다.**

---

## 추가 정보

- 뱃지 디자인은 자동 지정 조건과 수동 선택으로 구분하여 관리
- 기본 템플릿에서 원하는 뱃지가 없으면 새롭게 생성하여 사용 가능
- 조건 설정 관련 상세 내용은 "알파리뷰가 추천하는 자동 뱃지 조건 3가지" 섹션 참고
