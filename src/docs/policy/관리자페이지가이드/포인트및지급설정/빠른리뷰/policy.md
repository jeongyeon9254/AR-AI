# 빠른리뷰 가이드

## 개요

### 빠른리뷰란?

"빠른리뷰"는 알림톡 내에서 만족/보통/별로 버튼을 클릭하면 즉시 리뷰가 작성되는 기능입니다. 관리자가 미리 설정한 템플릿 텍스트가 자동으로 입력되며, 알파리뷰 파트너사의 높은 리뷰 작성률(22.8%)을 구현하는 핵심 기능입니다.

---

## 작성 프로세스

### 1단계: 알림톡 수신

상품 구매 고객에게 설정된 작성 유도 시점에 맞춰 리뷰 작성 유도 알림톡이 발송됩니다. 알림톡에는 만족/보통/별로 버튼이 포함되어 있습니다.

### 2단계: 작성페이지 진입

고객이 버튼(예: 만족)을 선택하면 리뷰 작성 페이지로 이동합니다. 텍스트리뷰 작성란에 관리자가 설정한 빠른리뷰 템플릿 내용이 자동으로 표시됩니다.

**주요 특징:**
- 고객이 별점을 수정하면 수정된 별점에 맞는 텍스트로 자동 변경
- 해당 페이지에서 모든 리뷰 항목에 대해 추가 작성 가능

### 3단계: 빠른리뷰 등록

- **템플릿만 사용 시:** 고객이 추가 작성 없이 페이지를 이탈하면 빠른리뷰 템플릿 내용 그대로 등록
- **추가 작성 시:** 고객이 텍스트를 추가 작성하면 빠른리뷰 템플릿 내용은 사라지고 고객의 작성 내용만 등록

## 포인트 설정

**접속 경로:** 기본 설정 > 포인트 지급 설정 > 일반 리뷰 지급 포인트

### 포인트 지급 방식

빠른리뷰는 고객이 직접 작성한 리뷰가 아닌 자동 생성 콘텐츠이므로 **텍스트 리뷰와 별개**로 취급됩니다. 따라서 **별점 리뷰 항목의 포인트**가 지급됩니다.

### 추가 작성 시 포인트 정책

- 빠른리뷰 작성 후 고객이 추가 작성 또는 수정 가능
- 단, 혜택 지급이 완료된 리뷰는 알파리뷰 정책상 추가 검수하지 않음
- 빠른리뷰 완료 후 추가 작성분에 대한 포인트는 리뷰 목록 메뉴에서 **수동으로 지급**해야 함

## 설정 방법

### 빠른리뷰 기능 사용 여부 설정

**접속 경로:** 기본 설정 > 리뷰 모아보기

- 빠른리뷰는 서비스 개시 시 기본 실행 상태
- 사용 원치 않을 경우 해당 위치에서 사용 여부 토글 비활성화
- **설정 변경 후:** 새로운 주문부터 적용 (기존 주문은 빠른리뷰 작성 가능 상태 유지)

### 빠른리뷰 템플릿 설정

**접속 경로:** 설정 > 빠른리뷰

#### 템플릿 구성

만족도별 템플릿 3가지를 설정합니다:

| 만족도 | 별점 | 설명 |
|--------|------|------|
| 만족 | 5~4점 | 긍정적 평가 템플릿 |
| 보통 | 3점 | 중립적 평가 템플릿 |
| 별로 | 2~1점 | 부정적 평가 템플릿 |

#### 템플릿 작성 가이드

- **고객 느낌의 자연스러운 문체로 작성** - 직접 작성한 리뷰처럼 보여야 함
- **템플릿 삭제 가능** - 만족도별 템플릿을 삭제해도 해당 별점의 빠른리뷰 작성 불가능한 것 아님
- **템플릿 미설정 시:** 선택된 만족도에 해당하는 템플릿이 없으면 시스템 기본값으로 자동 처리
  - 예) "고객님께서 해당 상품을 '별로'로 평가해 주셨습니다."

#### 이모지 변수

만족도별 이모지가 템플릿에 포함될 수 있습니다:

**만족 이모지:** 8개 중 1개 랜덤
**보통 이모지:** 6개 중 1개 랜덤
**별로 이모지:** 7개 중 1개 랜덤

**이모지 커스터마이징 방법:**
- 변수값 수정 불가능
- 변수를 삭제한 후 직접 원하는 이모지 입력 가능
- 각 템플릿에 1개 이모지만 랜덤 선택되어 작성됨

**템플릿 수정 시점:**
- 템플릿 수정 후 작성되는 리뷰부터 새로운 템플릿 적용
- 이전에 작성된 리뷰는 기존 템플릿으로 유지

#### 시스템 자동응답 리뷰

"시스템 자동응답 리뷰" 항목은:
- 리뷰 내용 수정 불가능
- 관리자 커스터마이징 불가능

## 주요 정책 및 제약사항

1. **템플릿 기본값:** 최초 설치 시 알파리뷰 기본값 텍스트로 설정, 이후 수정/삭제 가능

2. **별점 설정 고정:** 만족도별 별점은 수정 불가능
   - 만족: 5~4점
   - 보통: 3점
   - 별로: 2~1점

3. **혜택 지급 정책:** 혜택 지급이 완료된 리뷰는 추가 검수 대상 아님

4. **설정 반영 시점:** 템플릿/기능 설정 변경 후 새로 연동되는 주문부터 적용

5. **작성률 효과:** 빠른리뷰 기능 미사용 시 리뷰 작성률이 큰 폭으로 상승하지 않을 수 있음

## FAQ

**Q: 빠른리뷰로 작성된 리뷰도 포인트 지급 대상인가?**
A: 네. 텍스트 리뷰가 아닌 별점 리뷰 항목의 포인트가 지급됩니다.

**Q: 빠른리뷰 후 고객이 추가 작성했을 때 포인트는?**
A: 빠른리뷰 완료 후 혜택 지급이 이미 완료되었다면, 추가 작성분에 대해서는 리뷰 목록에서 수동으로 포인트를 지급해야 합니다.

**Q: 템플릿을 삭제하면 해당 별점 빠른리뷰를 작성할 수 없나?**
A: 아니요. 템플릿 삭제해도 빠른리뷰 작성 자체는 가능하며, 시스템 기본 문구가 자동 적용됩니다.

**Q: 이모지를 내가 원하는 것으로 바꿀 수 있나?**
A: 변수값 수정은 불가능하지만, 변수를 삭제 후 직접 이모지를 입력하면 됩니다.
