# 키워드 알림 및 필터 가이드

## 개요

Alpha Review의 키워드 알림 및 필터 기능은 부정적인 단어나 쇼핑몰에 표시되면 안 되는 키워드를 사전에 등록하여 리뷰 게시 전에 확인할 수 있는 도구입니다.

## 주요 특징

### 적용 시점
- 설정 완료 후 새롭게 작성되는 리뷰부터 설정이 적용됩니다
- 기존에 작성된 리뷰에는 적용되지 않습니다

### 데이터 유지
- 실제 리뷰 데이터도 필터링 단어로 변경됩니다
- 서비스 해지 시 호스팅사(카페24/아임웹)로 이관될 때도 필터링된 데이터로 전달됩니다

---

## 기능 설명

### 1. 키워드 알림

**기능**: "특정 단어가 포함된 리뷰가 작성되었을 때 리뷰가 자동으로 게시되지 않고 담당자의 검수가 이루어질 수 있도록"하는 기능입니다.

**설정 방법**:
1. 경로: [리뷰 관리 > 키워드 알림 및 필터 > 키워드 알림]
2. 검수할 키워드 입력
3. 필요시 우측 상단의 [아래 키워드가 작성 된 리뷰는 수동게시] 체크

**주의사항**:
- 띄어쓰기를 포함해 완전히 동일한 단어를 필터링합니다
- 예측 가능한 단어들을 모두 입력해야 합니다

### 2. 키워드 필터

**기능**: "특정 단어와 대체 단어를 입력하고, 해당 단어가 작성되었을 때 대체 단어로 자동 수정"되는 기능입니다.

**설정 방법**:
1. 경로: [리뷰 관리 > 키워드 알림 및 필터 > 키워드 필터]
2. 필터링할 단어와 대체 단어 입력
3. 예시: 필터링할 단어 "다이어트" → 대체 단어 "다\*\*트"

---

## 설정 전 주의사항

특정 단어 포함을 금지하는 설정은 제공되지 않습니다. 해당 기능은 검수 및 자동 수정 기능만 제공합니다.
