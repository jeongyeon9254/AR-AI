# 알파리뷰 리뷰 모아보기 가이드

## 개요

리뷰 모아보기는 고객이 작성할 수 있는 리뷰 항목을 설정하는 관리 기능입니다. "현재 활성화된 리뷰 항목이 고객이 작성 가능한 리뷰 종류"입니다.

## 접속 경로

**기본 설정 > 리뷰 모아보기**

## 활성화된 리뷰 종류

### 기본 활성화 항목
- **텍스트/포토 리뷰**: 기본값으로 활성화 상태

### 추가 활성화 가능 항목
- 빠른 리뷰
- 설문 리뷰
- 키워드 리뷰
- 미검증 리뷰

## 설정 방법

### 기본 설정
각 리뷰 종류의 활성화/비활성화는 토글 버튼으로 제어합니다.

### 상세 설정 이동
리뷰 항목 이름 오른쪽의 화살표를 클릭하면 해당 기능의 설정 페이지로 이동합니다. 또는 왼쪽 메뉴에서 리뷰 모아보기 하위의 기능명을 클릭해도 동일한 페이지로 이동합니다.

## 주요 정책 및 제약사항

### 데이터 적용 범위
"설정 변경 시 과거 주문 데이터는 변경되지 않으며, 새롭게 연동되는 주문 건부터 새로운 설정이 적용됩니다." 예를 들어, 설문 리뷰 항목을 활성화하면 기존 주문은 설문 리뷰 작성 불가 상태 유지, 이후 주문부터만 작성 가능합니다.

### 적용 대상 한정
"알파리뷰의 리뷰 작성 기능은 알파리뷰의 리뷰 작성 페이지로 접속되는 주문 데이터만 적용됩니다."

### 텍스트/포토 리뷰 비활성화
"텍스트/포토 리뷰 기능을 비활성화 시 모든 리뷰를 작성할 수 없게 됩니다." 이 기능을 비활성화하려면 1:1 채팅으로 문의해야 합니다.

### 특정 상품 제외 설정
특정 상품이나 카테고리에서 리뷰 작성을 불가능하게 하려면 "포인트 지급 설정"에서 리뷰 작성 불가 상품/카테고리를 지정할 수 있습니다.
