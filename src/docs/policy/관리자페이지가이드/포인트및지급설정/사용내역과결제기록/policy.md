# 사용 내역과 결제 기록 확인 가이드

## 개요
알파리뷰의 사용 내역 및 결제 기록을 확인하는 방법을 안내합니다.

## 청구서 확인 방법

### 접속 경로
**[구독관리]** 메뉴에서 확인 가능합니다.

### 주요 안내사항

- **결제 정책 변경**: 2025년 1월 1일부터 선불 결제로 변경되었으며, 사용 내역 발송은 중단되었습니다.
- **통일된 인터페이스**: 구독 관리 화면은 호스팅 사 상관없이 동일하게 제공됩니다.

### 결제 알림 메일

매월 1일 결제 완료 후 "결제 안내 메일"을 자동 발송합니다.

**메일 수신 설정:**
- 이메일 주소는 최대 1개까지만 등록 가능
- 메일 주소 변경 위치: **[설정 > 쇼핑몰 정보 설정]**
- 설정 후 최신화가 필요합니다

### 청구서 확인

"[구독 관리]" 페이지에서 직접 청구서를 확인할 수 있습니다.

## 주의사항

쇼핑몰을 운영 중인 호스팅 사를 기준으로 비용을 확인하세요.
