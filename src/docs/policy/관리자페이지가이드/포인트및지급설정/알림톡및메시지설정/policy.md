# 알림톡 및 메시지 설정 가이드

## 개요

알파리뷰의 알림톡 기능을 통해 고객에게 리뷰 작성을 유도하고 관리할 수 있습니다. 알림톡 발송과 리뷰 작성 가능 시점은 별도의 설정값이 적용되므로 주의가 필요합니다.

### 주요 주의사항

- "알림톡이 발송되는 시점과 리뷰를 작성할 수 있는 시점은 서로 다른 설정 값이 적용"됩니다
- 호스팅사(카페24/아임웹)의 배송 상태 연동이 늦으면, 알림톡 발송 후에도 리뷰 작성이 불가능할 수 있습니다
- 배송 기간이 짧은 경우 리뷰 작성 가능 시점을 "배송중" 설정으로 사용하길 권장합니다

---

## 알림톡이란?

### 알림톡의 종류

**리뷰 작성 유도 알림톡**
- 호스팅사(카페24/아임웹)에서 발생 및 수집된 주문 건을 기반으로 발송
- 기본적으로 모든 주문에 발송되나, 리뷰 작성 정책에 의해 일부 제외 가능

**회원 가입 유도 알림톡**
- 비회원이 리뷰 작성 후 포인트를 받으려면 회원가입이 필요한 경우 발송
- "자사몰 회원 가입 후 포인트를 지급 받으실 수 있다는 내용"이 포함됩니다

### 채널 설정의 중요성

카카오 비즈니스 채널을 미등록 상태에서는 "알파리뷰 프로필로 알림톡이 발송"됩니다. 현재 카카오 비즈니스 채널을 운영 중이라면 반드시 등록하기를 권장합니다.

**이유:**
- 고객이 알파리뷰로 배송/상품 문의를 할 수 있으나 응대 불가
- 리뷰 작성률에 부정적 영향

---

## 알림톡 & 메시지 설정

**접속 경로:** 기본 설정 > 알림톡 설정

### 주요 제약사항

- "알파리뷰의 알림톡 발송 시간은 지정되어있으며, 변경은 불가능"합니다
- 채널 등록 후 카카오 검수가 필요하며 영업일 기준 3~5일 소요됩니다

---

## 카카오 채널 ID 설정

**접속 경로:** 기본 설정 > 알림톡 설정 > 채널설정

### 설정 단계

1. **비즈니스 인증된 카카오톡 검색용 아이디 입력**
   - 비즈니스인증(관리 - 비즈니스 채널 신청) 완료 필수

2. **관리자 휴대폰번호로 인증**
   - "카카오톡 플러스 친구에 관리자로 등록된 휴대폰 번호만 인증 가능"합니다

3. **카카오 검수 대기**
   - 설정 후 카카오측 검수 3~5일 이후 등록 프로필로 메시지 발송 시작

4. **일일 최대 발송 메시지 수 설정**
   - 최소 1개, 최대 99개 설정 가능
   - 1명의 고객이 여러 주문을 분산 구매한 경우(공동구매 등) 알림톡 발송 횟수 제한 가능

### 설정 중 경고 문구 발생 시

설정 중에 경고 문구가 표시될 수 있습니다. 확인 후 진행하면 됩니다.

---

## 첫번째 리뷰 요청(최초 알림톡 발송 시점)

**접속 경로:** 기본 설정 > 알림톅 설정 > 첫번째 리뷰 요청

### 발송 기준

알림톡 발송 시점은 "CAFE24의 배송 상태를 기준으로" 설정합니다.

### 배송 상태 연동 메커니즘

- "실제 배송 여부와는 상관 없이, 호스팅사(카페24/아임웹)의 배송 상태를 기준으로 알림톡이 발송"됩니다
- 호스팅사에서 배송 완료로 변경 후 알파리뷰로 주문 건 연동, 그 후 알림톡 예약 발송
- 배송 데이터 연동에 최소 3~4시간 소요됩니다

### 설정 옵션

배송중 상태로부터 n일 후 또는 배송 완료 변경 당일 중 더 빠른 시점을 기준으로 알림톡 발송 가능

**예시:**
- 배송중 상태: 1월 10일
- 배송 완료 상태: 1월 15일
- 설정: "배송중으로부터 3일 후" 또는 "배송 완료 당일"
- 결과: 1월 13일 알림톡 발송(더 빠른 시점)

### 정책 적용 시점

"설정 변경 후 들어오는 주문 건부터 새로운 시점이 적용" 됩니다. 과거 주문 건에는 적용되지 않습니다.

---

## 리뷰 작성 리마인더

**접속 경로:** 기본 설정 > 알림톡 설정 > 리뷰 작성 리마인더

### 기능 설명

최초로 알림톡이 발송된 후 n일 경과 시 리뷰 미작성 고객에게 자동으로 리마인더 알림톡 발송합니다.

### 설정 범위

- 최소: 3일
- 최대: 30일

### 발송 조건

"리뷰 작성 가능 기한이 경과되었거나, 상품 수령 후 n일이 경과되어 리뷰를 작성하더라도 지급 받을 수 있는 포인트가 없다면 리마인더 알림톡은 발송되지 않습니다"

### 활성화 후 동작

"설정 on 직후부터 당일 또는 익일 리마인더 알림톡이 발송" 됩니다.

**예시:** 7일 후 리마인더 설정을 오늘 활성화한 경우, 오늘을 기준으로 7일 전에 발송한 첫 알림톡 대상 중 미작성 주문 건에 당일 또는 익일 리마인더 발송

### 정책 변경 반영

작성 정책 변경 후 새롭게 연동되는 리뷰부터만 새로운 설정이 적용됩니다. 과거 주문 건은 영향 없음.

### 저장

모든 설정 완료 후 우측 상단의 "저장하기" 버튼을 클릭합니다.

## 메시지 발송 내역 확인 방법

**접속 경로:** 기본 설정 > 알림톡 및 메시지 설정 > 발송 내역

### 조회 단계

1. 발송 내역 페이지로 이동
2. 우측 상단에서 고객명 또는 휴대폰번호로 검색
3. 알림톡 발송 시간 확인 가능

### 발송 내역 미표시 사유

호스팅사(카페24/아임웹)에서 배송완료 상태로 변경된 후 알파리뷰가 상태 변경을 인식하기까지 "최대 4시간 소요"됩니다. 배송완료 상태 변경 후 일정 시간이 경과해야만 발송 내역에서 확인 가능합니다.

---

## 발송 내역에서 확인되지 않는 리뷰가 있으신가요?

### 확인사항 1: 알림톡 발송 가능 시점 확인

**접속 경로:** 기본 설정 > 알림톡 및 메시지 설정 > 알림톡 설정

현재 설정된 발송 시점이 도래하지 않았을 수 있습니다.

### 확인사항 2: 혜택 지급 가능 고객 여부

**접속 경로:** 기본 설정 > 포인트 지급 설정

"혜택을 지급할 수 없는 고객이라면, 쇼핑몰 상에서 리뷰 작성은 가능하지만, 알림톡이 발송되지 않습니다"

#### 예외 사항

- "지급 받을 수 있는 적립금이 0p 더라도 알림톡은 발송" 됩니다
- 리뷰 작성이 제한되어 있는 고객(설정상 리뷰 자체 작성 불가)인 경우 알림톡 미발송
- 비회원 고객의 포인트 지급 수준이 0p인 경우, "리뷰를 작성했음에도 지급 받을 수 있는 적립금이 없기 때문에 회원가입 유도 알림톡은 발송되지 않습니다"

---

## 추가 참고사항

### 테스트 알림톡

현재 체험용 이외의 테스트 알림톡 기능을 제공하지 않습니다. 고객에게 발송될 알림톡을 확인하고 싶다면 "리뷰 요청" 기능으로 임의의 주문 건을 생성하여 테스트합니다.

### 현재 발송 프로필 확인

설정된 카카오 채널과 알파리뷰 프로필 중 어느 것으로 발송되는지는 채널설정 페이지에서 확인할 수 있습니다.
