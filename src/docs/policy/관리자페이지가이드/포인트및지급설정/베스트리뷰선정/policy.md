# 베스트 리뷰 선정 방법 가이드

## 개요

베스트 리뷰는 알파리뷰에서 우수한 리뷰를 별도로 관리하고 전시할 수 있는 기능입니다. 베스트 리뷰 북마크를 등록한 리뷰들이 전용 위젯을 통해 고객에게 노출됩니다.

---

## 베스트 리뷰 기능 사용 전 필독 사항

### 위젯 설치 필수
- 베스트 리뷰 위젯이 아직 설치되지 않은 영역에서 사용하려면 **반드시 위젯 추가 설치가 필요**합니다
- 기존 설치 위젯은 추가 설치하지 않아도 됩니다

### 순위 지정 자동화
- 별도 순위 지정이 없어도 베스트 리뷰 북마크 등록 순서대로 자동 순위 지정됩니다
- 게시 순위를 변경하려면 추가 설정 필요합니다

### 시각적 표시
- 베스트 리뷰 북마크 등록 시 **리뷰에 별도 문구가 자동 노출되지 않습니다**
- 리뷰에 시각적 표시가 필요하면 뱃지 기능을 사용해야 합니다

### 고객 혜택 미제공
- 베스트 리뷰 선정 시 고객에게 자동 알람이 발송되지 않습니다
- 추가 적립금은 자동 지급되지 않으며, 수동으로만 가능합니다

---

## 베스트 리뷰 위젯 미리보기

### 디바이스별 UI
- **모바일 버전**: 세로 레이아웃으로 베스트 리뷰 3개 표시
- **PC 버전**: 가로 카드 레이아웃으로 베스트 리뷰 3개 표시

### 위젯 작동 방식
"베스트 리뷰 북마크" 기본 설정으로 제공되므로, 별도 필터 설정 변경 불필요합니다. 북마크 등록 리뷰가 자동으로 표시됩니다.

### 순위 표시
- 1st, 2nd, 3rd 순위 배지가 기본 제공됩니다
- 위젯 설정에서 순위 표시 비활성화 가능합니다
- 커스텀 이미지 대체는 "커스텀 에디터 위젯"으로 가능합니다

### 빈 위젯 처리
베스트 리뷰 북마크가 등록된 리뷰가 없으면 위젯은 페이지에 노출되지 않습니다.

### 상품 상세페이지 자동 필터링
상품 상세페이지에 베스트 리뷰 위젯을 추가하면 해당 상품에 작성된 리뷰만 필터링되어 표시됩니다.

---

## 베스트 리뷰 위젯 추가 방법

### 단계별 설정 프로세스

1. **디자인 설정 접근**: [디자인 설정 > 위젯 세트 관리] 경로로 이동
2. **수정 모드 진입**: 변경할 영역 세트의 설정 버튼(⚙️) 클릭
3. **위젯 추가**: "+ 위젯 추가" 버튼으로 베스트 리뷰 위젯 선택
4. **순서 조정**: 삼선 아이콘(☰)을 드래그하여 위젯 배치 순서 변경

### 관련 가이드 문서
- 배너 이미지/텍스트를 추가하려면 커스텀 에디터 위젯 활용

## 베스트 리뷰로 선정할 리뷰 등록

### 라벨 등록 방법

1. **리뷰 선택**: 리뷰 목록에서 베스트 리뷰로 지정할 리뷰 확인
2. **북마크 클릭**: 리뷰 하단의 북마크 아이콘 클릭
3. **라벨 설정**: "베스트 리뷰" 북마크 옵션 선택
4. **삭제 방법**: 동일 북마크를 다시 클릭하면 기존 북마크 제거

### 조회 기간 설정
- 대시보드 초기 접속 시 최근 3개월 리뷰만 표시
- 과거 리뷰 선정 시 조회 기간을 확대하여 검색

### 관리 팁
[북마크로 검색] 메뉴에서 북마크 등록된 리뷰만 별도 모아볼 수 있어 관리가 용이합니다.

### 포인트 지급 제약
- 알파리뷰 대시보드에서는 **알파리뷰로 작성된 리뷰에만 적립금 지급 가능**
- 다른 경로의 리뷰에는 포인트 지급 불가

---

## 베스트 리뷰 순위 지정 및 변경

### 순위 지정 전제 조건
"상단 고정" 설정된 리뷰에만 게시 순위 지정이 가능합니다.

### 순위 변경 프로세스

1. **상단 고정 설정**: 베스트 리뷰 북마크 리뷰 모두를 상단 고정
2. **순위 조정**: 상단 고정된 리뷰의 게시 순위 변경
3. **자동 반영**: 변경된 순위가 위젯에 즉시 반영

### 상태 확인 제약
상단 고정되지 않은 리뷰는 순위 지정 불가능 상태입니다.
