# 비회원도 리뷰를 작성할 수 있나요?

## 개요
알파리뷰에서는 비회원도 리뷰 작성이 가능하며, 설정에 따라 비회원에게 포인트 혜택을 지급할 수 있습니다.

## 주요 기능

### 비회원 리뷰 작성 조건
- **접속 경로**: [기본 설정 > 포인트 지급 설정 > 리뷰 작성 조건]
- 비회원이 리뷰를 작성할 수 있도록 설정 가능
- 호스팅사(카페24/아임웹)에서 연동된 리뷰에는 혜택 지급 불가능

### 비회원 포인트 지급 설정
- **접속 경로**: [기본 설정 > 포인트 지급 설정 > 일반 리뷰 지급 포인트]
- 비회원이 리뷰 작성 시 지급할 포인트 금액 설정
- "비회원 종류에 따라 포인트 별도 설정" 활성화 시 일반 비회원과 Npay 구매 비회원의 혜택을 따로 설정 가능

### 비회원과 Npay 비회원의 차이
- **비회원**: 회원 가입이 되어있지 않은 모든 고객
- **Npay 비회원**: 네이버페이로 구매한 비회원 고객으로, 별도 데이터 취급하여 자사몰에서도 리뷰 작성 가능하도록 지원

## 회원 가입 유도 알림톡

### 알림톡의 역할
비회원이 리뷰 작성 후 지급받을 포인트가 있을 때 발송되며, 고객을 회원 가입으로 유도하는 기능입니다.

### 발송 조건
- "지급 받을 수 있는 포인트가 없으면 발송 안 됨"
- 고객이 수신 동의를 해야만 발송됨
- 2026년 3월 개정 정보통신망법에 따라 광고성 메시지로 판단되어 수신 동의 필수

### 비회원 포인트 지급 프로세스

1. 비회원이 상품 구매 후 리뷰 작성
2. 회원 가입 유도 알림톡 수신 동의
3. 해당 리뷰에 지급받을 포인트 발생 시 확인
4. 회원 가입 유도 알림톡 발송
5. 고객이 쇼핑몰 회원 가입 후 회원 정보 입력
6. 리뷰 작성 혜택 지급

**소요 시간**: 수/자동 지급 모두 최소 3~4시간 필요

### 포인트 지급 여부
"검수 설정"의 설정값(수/자동 지급 설정)이 적용됩니다.

## 회원 가입 유도 알림톡 수신 동의 방법

### 수신 동의 방식
비회원이 리뷰 작성 후 저장 버튼을 누르면, 페이지 상단에 회원 가입 유도 알림톡의 수신 동의 여부를 활성화할 수 있습니다.

### 수신 동의 미설정 시 처리방법
- 수신 동의 설정이 비활성화되면 알림톡 미발송
- 고객은 리뷰 작성페이지에서 "[비회원 작성으로 대기 중인 포인트 받기]" 버튼으로 지급 신청
- 리뷰 1개씩이 아닌 한 번에 모든 대기 포인트 지급됨

### 리뷰 작성페이지 접속 방법 (3가지)
1. 알림톡 링크
2. 자사몰의 "리뷰 작성하기" 버튼
3. 대시보드에서 제공 링크

## 중요 사항

### 비회원 혜택 지급 전 필독
- 알파리뷰 대시보드에서는 "알파리뷰의 리뷰 작성 페이지"에서 작성된 리뷰에만 혜택 지급 가능
- 네이버페이 고객에게도 자사몰에서 혜택을 지급하려면 [기본 설정 > 포인트 지급 설정]에서 설정 변경 필요
- 회원 가입 후 정보를 입력하지 않으면 포인트 지급 대상을 알 수 없어 실제로는 지급되지 않음

### 포인트 지급 대기 상태
비회원이 리뷰를 작성했더라도 지급받을 수 있는 포인트가 없으면 회원 가입 유도 알림톡 미발송
