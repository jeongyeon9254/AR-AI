# 미검증 리뷰 가이드

## 개요

미검증 리뷰는 주문(구매) 건이 확인되지 않는 리뷰입니다. 서포터즈 운영이나 오프라인 중심 쇼핑몰처럼 카페24 상에서 주문 기록이 없는 경우에 활용할 수 있습니다.

## 미검증 리뷰 정책

### 핵심 제약사항

- **1일 최대 작성 건수**: 5/10/15/20개 중 선택 가능
- **자동 처리 불가**: 수동 게시 및 적립금 지급만 가능하며, 자동 게시·지급 불가
- **대상**: 로그인한 회원 중 자사몰 주문 건이 없는 경우만 가능
- **작성 위치**: 상품 상세페이지의 알파리뷰 위젯 내 리뷰 작성 버튼에서만 작성 가능
  - 메인페이지, 전체 후기 게시판 제외

### 사용자별 제약사항

| 대상 | 가능 여부 | 대안 |
|------|---------|------|
| 비회원 | 불가 | 회원 가입 후 작성 또는 리뷰 요청 기능으로 주문 건 생성 |
| 기존 구매 고객 (주문 건 1+) | 불가 | 리뷰 요청 기능으로 임의 주문 건 생성 후 일반 리뷰 작성 |
| 주문 건 없는 회원 | 가능 | - |

### SNS 리뷰 제약

"알파리뷰의 SNS 리뷰 기능은 상품을 구매한 고객을 기준으로 합니다" - 미검증 리뷰로는 SNS 리뷰 작성 불가. 협찬/서포터즈 SNS 리뷰는 리뷰 요청 기능으로 주문 건 생성 후 일반 리뷰 작성 후 SNS 리뷰 추가 필요.

## 설정 방법

### 1단계: 미검증 리뷰 기능 활성화

**접속 경로**: 기본 설정 > 포인트 지급 설정

1. 리뷰 작성 조건에서 미검증 리뷰 기능 활성화
2. 기본값은 비활성화 상태로, 활성화 후 이용 가능

### 2단계: 최초 설정 구성

미검증 리뷰 활성화 시 설정 창이 표시됨:
- 리뷰 정책 관련 설정 완료 필요

### 3단계: 혜택 지급 수준 설정

**접속 경로**: 포인트 지급 설정

- 적립금 지급 여부 선택
- 체크박스 선택 후 설정 완료
- 설정 시 이후 작성 리뷰부터 적용
- SNS리뷰 적립금 설정은 미검증 리뷰에서 불가능

### 4단계: 검증 표시 아이콘 설정

**접속 경로**: 디자인 설정 > 공통 디자인

- 기본 설정: 실제 구매자 리뷰에만 검증 아이콘 표시
- 활성화 상태: 관리자 리뷰, 미검증 리뷰는 아이콘 미노출
- 비활성화 상태: 전체 리뷰 검증 표시 아이콘 미노출

## 사용자가 미검증 리뷰 작성하는 방법

1. 쇼핑몰 접속 및 로그인 (필수)
2. 리뷰 작성 필요한 상품의 상세페이지 이동
3. 알파리뷰 위젯의 "리뷰작성하기" 버튼 클릭
4. 미검증 리뷰 팝업창에서 "확인" 버튼 클릭
5. 새 창의 리뷰 작성페이지에서 리뷰 작성

### 작성 시 주의사항

- **포인트 미노출**: 리뷰 작성페이지에 "포인트 지급 불가" 문구 표시 (자연스러운 현상)
  - 필요 시 대시보드에서 수동으로 포인트 지급
- **옵션 수동 입력 필요**: 실제 주문과 달리 구매 옵션이 자동 입력되지 않으므로 수동으로 직접 입력 필요

## 미검증 리뷰 관리 관련 주의사항

### 수정/삭제 제약

"일반 리뷰와는 달리 미검증 리뷰는 고객이 리뷰 작성페이지 내에서 리뷰 내용을 수정/삭제하는 것이 불가능합니다"

**관리 방법**:
- 고객이 수정/삭제하려면 관리자에게 요청 필요
- 관리자는 대시보드에서 직접 수정 또는 삭제
- 또는 리뷰 요청 기능으로 임의 주문 건 생성 후 일반 리뷰로 전환
