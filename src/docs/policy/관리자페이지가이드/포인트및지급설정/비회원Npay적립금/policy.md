# 비회원, Npay, Zpay 구매 고객 적립금 지급 가이드

## 개요

알파리뷰에서 비회원 고객이 리뷰를 작성할 때 적립금(포인트)을 지급하는 방식과 절차를 설명합니다.

## 주요 내용

### 비회원 혜택 지급 전 필독사항

**중요 제약사항:**
- 알파리뷰 대시보드는 "알파리뷰의 리뷰 작성 페이지"에서 작성된 리뷰에만 혜택을 지급할 수 있습니다
- 호스팅사(카페24/아임웹)에서 연동된 리뷰에는 혜택 지급이 불가능합니다
- 비회원이 리뷰를 작성했더라도 지급받을 수 있는 포인트가 없으면 회원 가입 유도 알림톡은 발송되지 않습니다

### 비회원도 리뷰를 쓸 수 있나요?

가능합니다. 메뉴 위치: **[기본 설정 > 포인트 지급 설정 > 리뷰 작성 조건]**

리뷰 작성 조건에서 비회원 리뷰 작성을 허용하도록 설정해야 합니다.

### 비회원 포인트 지급 설정

메뉴 위치: **[기본 설정 > 포인트 지급 설정 > 일반 리뷰 지급 포인트]**

**설정 옵션:**
- 비회원이 리뷰를 작성했더라도 지급받을 포인트가 없으면 혜택을 받을 수 없습니다
- "비회원 종류에 따라 포인트 별도 설정" 옵션을 활성화하면 비회원과 Npay 구매 비회원의 혜택을 따로 설정할 수 있습니다

#### 비회원과 Npay 비회원의 차이

- **비회원**: 회원 가입이 되어 있지 않은 모든 고객
- **Npay 비회원**: 비회원 중에서도 네이버 페이(Npay)로 구매한 고객
  - 네이버뿐만 아니라 자사몰에도 리뷰를 작성할 수 있도록 기능 제공
  - 별도의 포인트 설정 가능

### 회원 가입 유도 알림톡이란?

비회원 고객이 리뷰 작성 후 회원 가입을 유도하기 위해 발송되는 알림톡 메시지입니다.

**발송 조건:**
- 비회원이 지급받을 수 있는 포인트가 존재해야 함
- 고객의 수신 동의가 필요함

**법적 근거:**
"2026년 3월 개정된 정보통신망 이용촉진 및 정보보호 등에 관한 법률에 따라 회원 가입 유도 알림톡이 광고성 메시지로 판단될 여지가 있어" 고객의 직접 수신 동의가 필수입니다.

### 비회원 포인트 지급 과정

**6단계 절차:**

1. 상품을 구매한 비회원이 리뷰를 작성하고 회원 가입 유도 알림톡 수신 동의를 함
2. 해당 리뷰에 지급받을 수 있는 포인트가 발생
3. 포인트 지급 여부가 확인됨
4. 회원가입 유도 알림톡이 발송됨
5. 고객이 쇼핑몰 회원 가입 후 회원 정보를 입력
6. 모든 과정이 정상 완료되면 입력한 고객 정보로 리뷰 작성 혜택이 지급됨

**소요 시간:**
- 수/자동 지급 모두 실제 고객에게 지급되기까지 최소 3~4시간 소요
- 시스템상 실제 포인트 지급까지 최대 1일 소요 가능

**포인트 지급 정책:**
"포인트 지급 여부는 검수 설정의 설정값이 적용됩니다" (수/자동 지급 설정)

### 회원 가입 유도 알림톡 수신 동의 방법

**동의 절차:**
비회원 고객이 리뷰를 작성하고 저장 버튼을 누르면, 페이지 상단에 회원 가입 유도 알림톡의 수신 동의 여부를 활성화할 수 있습니다.

**수신 동의 미설정 시 대응 방법:**

수신 동의 설정이 활성화되어 있지 않으면:
- 회원 가입 유도 알림톡이 발송되지 않음
- 고객이 리뷰 작성페이지에서 "[비회원 작성으로 대기 중인 포인트 받기]" 버튼을 눌러 포인트 지급을 신청해야 함
- 해당 고객에게 지급 대기 중인 모든 포인트가 신청 1번으로 한꺼번에 지급됨
- 리뷰 1개씩 모두 지급 신청할 필요 없음

**알파리뷰 리뷰 작성 페이지 접속 방법 (3가지):**
1. 알림톡
2. 자사몰의 "리뷰 작성하기" 버튼
3. 대시보드에서 링크 확인
