# 포인트 및 지급 설정

## 개요

알파리뷰의 포인트 지급 설정은 관리자 페이지에서 리뷰 작성 고객에게 제공하는 적립금 정책을 구성하는 기능입니다. 쇼핑몰의 리뷰 관련 적립금 정책에 맞춰 포인트 지급 수준을 사전에 변경하여 사용해야 합니다.

## 필독사항 및 주의사항

### 초기 설정 확인
알파리뷰 최초 설정 시 포인트는 기본값이 입력되어 있으므로 쇼핑몰의 리뷰 적립금 정책에 맞춰 변경 후 사용.

### 호스팅사 연동 및 설정 우선순위
- 알파리뷰 이용 시 기존 호스팅사(카페24/아임웹) 설정 무시, 알파리뷰 설정값에 맞춰 적립금 지급
- 모든 리뷰 관련 설정은 알파리뷰 대시보드에서 변경
- 실제 적립금 지급은 API를 통해 호스팅사에서 처리

### 포인트 지급 대상 제한
- 알파리뷰 어드민에서는 알파리뷰를 통해 작성된 리뷰에만 적립금 지급 가능
- 네이버페이, 스마트스토어 등 호스팅사 연동 리뷰는 지급 불가
- 호스팅사 자체에서 작성된 리뷰는 알파리뷰 어드민에서 지급 불가

### 알림톡 발송 제한
리뷰 작성 제한 또는 포인트 지급 제한 시 리뷰 작성 유도 알림톡 발송되지 않음. (포인트 0p 경우 제외)

### 설정 변경 적용 시점
- 리뷰 작성 조건 변경: 이후 새롭게 연동되는 주문 건부터 적용
- 포인트 지급 수준 변경: 변경 후 작성되는 리뷰부터 반영
- 과거 주문 건의 설정은 변경되지 않음

### 비회원 관련 정책
비회원 고객은 회원 가입 후 적립금을 지급받음.

## 1. 리뷰 작성 조건

**접속 경로:** `기본 설정 > 포인트 지급 설정 > 리뷰 작성 조건`

- **1-1. 작성 가능한 고객** — 작성 대상 고객 범주 설정
- **1-2. 리뷰 작성 기한** — 리뷰 작성 가능 기간 설정
- **1-3. 미검증 리뷰** — 검증되지 않은 리뷰의 처리 방식
- **1-4. 포인트 지급 후** — 포인트 지급 이후 리뷰 관리 정책
- **1-5. 리뷰 작성 제외 상품 및 카테고리** — 특정 상품/카테고리 제한 및 해당 구매 고객 알림톡 발송 제외

## 2. 리뷰 지급 포인트 설정

**접속 경로:** `기본 설정 > 포인트 지급 설정 > 일반 리뷰 지급 포인트`

### 2-1. 회원/비회원 지급 포인트 설정
회원과 비회원에 별도 포인트 지급 수준 설정. 변경 후 작성되는 리뷰부터 반영.

### 2-2. 일반 리뷰 지급 포인트 설정

#### 누적 지급 방식
알파리뷰 적립금은 누적 지급되며, 누적 방식 변경 불가. 작성한 리뷰 항목만큼 모두 포인트 지급됨.

#### 정액제
고정 포인트를 설정해 리뷰 작성 시마다 동일한 포인트 지급.

#### 정률제
상품 구매 금액의 일정 비율을 포인트로 지급. 정률제 사용 시 상품 금액은 **할인가** 기준 적용.

예시: 30,000원 구매 시 10% 정률 → 3,000원 지급 / 25,000원 → 2,500포인트.

⚠️ 호스팅사(카페24/아임웹) 쿠폰 할인은 **할인 전** 상품구매금액 기준 적용.

### 2-3. 포인트 상세 설정
리뷰 퀄리티 및 작성률을 높이기 위한 추가 포인트 설정. 변경 후 연동되는 주문부터 반영.

### 2-4. 포인트 최소값/최대값 설정
- **최소값**: 리뷰 1개당 적립금 지급 하한선
- **최대값**: 우측 상단 [최대값 설정]에서 혜택 제한 가능

변경 후 연동되는 주문부터 반영.

## 3. 기타 포인트 설정

**접속 경로:** `기본 설정 > 포인트 지급 설정 > 기타 포인트 설정`

- **3-1. 조기 작성 혜택** — 작성 기한 이전 작성 시 추가 포인트
- **3-2. 포인트 지급 제한** — 포인트 지급 기능 활성화/비활성화
- **3-3. 포인트 지급 제외 조건** — 특정 조건 주문 리뷰 포인트 제외
- **3-4. 포인트 회수** — 특정 조건 리뷰의 포인트 회수
- **3-5. 포인트 지급 제외 상품 및 카테고리** — 제외된 상품/카테고리 구매 고객은 리뷰 작성 유도 알림톡도 미발송

## FAQ

### Q. 리뷰 작성 조건 변경이 과거 주문에 적용되나요?
변경되지 않음. 새 주문 건부터 적용.

### Q. 리뷰 작성 불가능한 고객에게는?
알림톡 발송되지 않음.

### Q. 정률제에서 쿠폰 할인은?
할인 **전** [상품구매금액] 기준 계산.

### Q. 비회원이 리뷰 작성 시 포인트?
회원 가입 후 지급.
